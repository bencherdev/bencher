## 🕸 JavaScript Benchmark

Der JavaScript Benchmark Adapter (`js_benchmark`) erwartet Ausgaben von [Benchmark.js](https://github.com/bestiejs/benchmark.js).
Jeder Benchmark wird so benannt, wie Benchmark.js ihn ausgibt, ohne Parameter.
Die `throughput` Measure (d.h. `operations / second (ops/s)`) wird mit diesen Metriken erfasst:
- `mean`: die Rate, die Benchmark.js ausgibt
- `mean_ci95_lower` und `mean_ci95_upper`: das 95-%-Konfidenzintervall, aus der relativen Fehlermarge, die Benchmark.js neben der Rate ausgibt

Ein Benchmark mit einem einzelnen Lauf hat nur seinen `mean`.
Legen Sie zuerst für die Metrik `mean` einen Schwellenwert fest, mit `--threshold-metric mean`.
