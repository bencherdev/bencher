### `--allow-failure`

<br />

Опционально: Разрешить сбой теста производительности.
Если итерация команды бенчмарка завершается сбоем, `bencher run` выводит сбой и пропускает эту итерацию:
её вывод не разбирается, поэтому ни один из её результатов не отправляется.
Оснастка для бенчмарков, которая завершается с ошибкой при сбое любого одного бенчмарка, например asv или Catch2,
теряет результаты всей этой итерации.
