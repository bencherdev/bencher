## `--threshold-parameters <PARAMETERS>`

<br />

Используйте указанный фильтр параметров для порога в виде объекта JSON (пример: `--threshold-parameters '{"size": 512}'`).
Порог проверяет каждый [Вариант][variant], Параметры которого содержат каждый ключ объекта с тем же значением,
поэтому `{"size": 512}` соответствует и `{"op": "read", "size": 512}`, и `{"op": "write", "size": 512}`.
Значение задается в JSON, а не в форме `size=512`, которую показывают комментарий к запросу на вытягивание и Console.
Если опция не задана или задана как `{}`, порог проверяет каждый Вариант.
Чтобы игнорировать эту опцию для конкретного порога, используйте подчеркивание (`_`).
Порогу с фильтром параметров также нужна [опция `--threshold-metric`](#--threshold-metric-metric).
В BMF версии 0 `--threshold-parameters` останавливает `bencher run` с ошибкой до того, как что-либо будет отправлено.

Каждая опция `--threshold-parameters` содержит один набор Параметров.
Чтобы проверять Варианты, которые соответствуют любому из нескольких наборов, используйте API:
в BMF версии 1 `thresholds` Отчета перечисляют каждый порог с его фильтром `parameters` в виде списка наборов.
