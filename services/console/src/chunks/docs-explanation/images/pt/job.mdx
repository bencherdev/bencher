### `--job <UUID>`

<br />

Opcional: Conecta-se a um [Job em hardware dedicado][job].
Na maioria das vezes, esta opção é usada quando uma invocação separada do `bencher run`
já usou [a flag `--detach`][detach].
Várias outras opções do `bencher run` entram em ação e funcionam como se você nunca tivesse desanexado.
Isso permite aguardar Jobs em hardware dedicado de forma assíncrona usando callbacks
(webhooks por invocação do `bencher run`).

Veja [Pull Requests em hardware dedicado][pull requests on bare metal] para um exemplo usando o GitHub Actions.
