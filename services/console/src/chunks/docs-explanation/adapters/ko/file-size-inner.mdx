### ⚖️ File Size

<code><a href="/ko/docs/explanation/bencher-run/">bencher run</a></code> CLI 서브커맨드는
`--file-size` 옵션으로 결과물의 파일 크기(즉, 바이너리 크기)를 추적하는 데 사용할 수 있습니다.
`--file-size` 옵션에는 크기를 측정할 파일의 경로를 지정합니다.
내부적으로 <code><a href="/ko/docs/explanation/bencher-run/">bencher run</a></code>은
결과를 프로젝트의 BMF 버전으로 된 [Bencher Metric Format (BMF) JSON][bmf]으로 출력합니다.
따라서 명시적으로 [`json` 어댑터][json]를 사용하는 것이 좋습니다.
자세한 내용은 [파일 크기를 추적하는 방법][file size]을 참조하세요.

`file-size` 측정(즉, `bytes (B)`)은 하나의 `value` 메트릭으로 수집되며,
이것이 먼저 임계값을 설정할 메트릭입니다.
`file-size` 측정은 모든 프로젝트에 기본적으로 생성되지 않습니다.
하지만 `--file-size` 옵션을 사용하면 이 측정이 프로젝트에 자동으로 생성됩니다.
`--file-size` 옵션을 여러 번 사용하여 여러 파일의 크기를 추적할 수 있습니다.
