### 호스트 튜닝

각 벤치마크 전에, `runner`는 측정 노이즈를 줄이기 위해 호스트 튜닝을 적용합니다.
기본적으로 ASLR, NMI 워치독, SMT / 하이퍼스레딩, 터보 부스트를 비활성화하고,
CPU 스케일링 거버너를 `performance`로, swappiness를 `10`으로, `perf_event_paranoid`를 `-1`로 설정합니다.
마지막 부팅 이후 `runner`가 튜닝하지 않은 호스트에서는, 아래 플래그가 개별 최적화를 대신 호스트 기본값으로 유지합니다.

호스트 튜닝은 호스트가 재부팅될 때까지 유지됩니다. 각 설정은 런타임 전용 쓰기이며, `runner`는 종료할 때 이를 되돌리지 않습니다. 단, C-state 유지는 `runner`가 종료될 때 해제됩니다.
튜닝된 실행 이후에는, 그 밖의 설정을 건너뛰는 플래그가 다음 재부팅부터 적용됩니다. 그때까지 해당 설정은 튜닝된 값을 유지하며, `runner`는 시작할 때 그 값을 로그로 남깁니다.
공유 호스트는 `runner`를 제거한 후 재부팅하세요.

### `--no-tuning`

모든 호스트 튜닝 최적화를 비활성화합니다.

### `--aslr`

ASLR을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--nmi-watchdog`

NMI 워치독을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--smt`

SMT / 하이퍼스레딩을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--turbo`

터보 부스트를 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--numa-balancing`

자동 NUMA 밸런싱을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--timer-migration`

타이머 마이그레이션을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--soft-watchdog`

소프트 락업 워치독을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--ksm`

KSM(커널 동일 페이지 병합)을 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--cstates`

깊은 C-state를 비활성화하지 않습니다(기본값: 벤치마크에서는 비활성화).

### `--no-irq-steering`

디바이스 IRQ와 커널 워크큐를 하우스키핑 코어로 보내지 않습니다.

### `--no-cpuset-partition`

격리된 cpuset 파티션을 통해 벤치마크 코어를 스케줄러에서 분리하지 않습니다.

### `--swappiness <SWAPPINESS>`

swappiness 값을 설정합니다.
기본적으로 `10`이 사용됩니다.

### `--governor <GOVERNOR>`

CPU 스케일링 거버너를 설정합니다.
기본적으로 `performance`가 사용됩니다.

### `--perf-event-paranoid <PERF_EVENT_PARANOID>`

`perf_event_paranoid` 값을 설정합니다.
기본적으로 `-1`이 사용됩니다.

### `--thp <THP>`

호스트의 transparent hugepage 모드를 `never`, `madvise`, `always`, `leave` 중 하나로 설정합니다.
`leave`를 사용하면 호스트의 현재 모드를 유지합니다.
기본적으로 `never`가 사용됩니다.
