### Parameters
パラメータとは、`{"size": 64}` のように、ベンチマークを実行したときの入力です。
各キーは文字列、数値、またはブール値に対応し、1つのベンチマークのパラメータが持てるキーは最大 `8` 個です。
1組のパラメータを持つベンチマークがバリアントです。
そのため、複数組のパラメータで実行されるベンチマークは組ごとに1つのバリアントを持ち、
Bencher は各バリアントのメトリクスを個別に追跡します。
パラメータのないベンチマークは、空のパラメータを持つ単一のバリアントを持ちます。

パラメータは [Bencher Metric Format (BMF)][bmf] バージョン 1 の一部であり、
[ベンチマークハーネスアダプタ][adapters] は可能な場合にベンチマークハーネスからパラメータを読み取ります。
