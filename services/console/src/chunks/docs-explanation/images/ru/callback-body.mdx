### `--callback-body <JSON>`

<br />

Необязательно: Задает JSON-тело запроса callback.
Эта опция требует, чтобы была задана [опция `--callback-url`](#--callback-url-url).
Без `--callback-body` телом является отчет Job,
тот же JSON, который возвращает `GET /v0/projects/{project}/reports/{report}`.
Отчет указывает свой Job по UUID (`job`), но не сообщает состояние Job,
поэтому, чтобы узнать, завершился ли Job с ошибкой, пусть получатель прочитает Job с помощью `GET /v0/projects/{project}/jobs/{job}`, или отправьте `{{ job.status }}` в теле.
В приватном Проекте этот отчет содержит приватные результаты Проекта, поэтому отправляйте его только получателю, которому вы доверяете.

Строковое значение в теле, которое в точности равно одному из этих заполнителей, отправляется как его значение:

| Заполнитель          | Значение                                                     |
| -------------------- | ------------------------------------------------------------ |
| `{{ job.uuid }}`     | UUID Job                                                     |
| `{{ job.status }}`   | Конечное состояние Job: `processed`, `failed` или `canceled` |
| `{{ report.uuid }}`  | UUID отчета                                                  |
| `{{ project.uuid }}` | UUID Проекта                                                 |
| `{{ project.slug }}` | Slug Проекта                                                 |
| `{{ report }}`       | Весь отчет                                                   |

Пробелы внутри фигурных скобок необязательны, поэтому `"{{job.uuid}}"` тоже работает.
Каждое значение является JSON-строкой, кроме `{{ report }}`, который является самим отчетом,
тем же JSON, что и тело без `--callback-body`, с теми же приватными результатами.
Поэтому тело `"{{ report }}"` равнозначно отсутствию `--callback-body`,
а `{"event": "bencher", "report": "{{ report }}"}` помещает отчет в ваш собственный конверт.
Тело может содержать `{{ report }}` только один раз.
Любая другая строка, любой ключ и любое другое значение отправляются как есть.
Заполнитель внутри более длинной строки (например, `"Job {{ job.uuid }}"`) является обычным текстом, и ветвлений нет,
поэтому получатель, которому нужен результат, читает `{{ job.status }}`.
Строка, которая начинается с `{{` и заканчивается на `}}`, но называет что-то другое, является ошибкой, а не пустой строкой.
Тело может занимать не более 64 КиБ, при этом каждый заполнитель считается по его самому длинному значению, а `{{ report }}` не считается.
Перед отправкой Job `bencher run` проверяет тело, и сервер проверяет его еще раз.
