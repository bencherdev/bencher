### ホストチューニング

各ベンチマークの前に、`runner` は測定ノイズを低減するためにホストチューニングを適用します。
デフォルトでは、ASLR、NMI ウォッチドッグ、SMT / ハイパースレッディング、ターボブーストを無効にし、
CPU スケーリングガバナーを `performance`、swappiness を `10`、`perf_event_paranoid` を `-1` に設定します。
前回の起動以降に `runner` がチューニングしていないホストでは、以下のフラグは、個々の最適化を無効にせず、ホストのデフォルト値のまま維持します。

ホストチューニングはホストが再起動するまで持続します。各設定は実行時のみの書き込みであり、`runner` は終了時にそれを元に戻しません。ただし、C ステートの保持は `runner` の終了時に解除されます。
チューニングを行った実行の後では、それ以外の設定をスキップするフラグは次回の再起動から有効になります。それまでは、その設定はチューニングされた値のままであり、`runner` は起動時にその値をログに出力します。
共有ホストでは、`runner` を削除した後にホストを再起動してください。

### `--no-tuning`

すべてのホストチューニング最適化を無効にします。

### `--aslr`

ASLR を無効にしません (デフォルト: ベンチマークでは無効)。

### `--nmi-watchdog`

NMI ウォッチドッグを無効にしません (デフォルト: ベンチマークでは無効)。

### `--smt`

SMT / ハイパースレッディングを無効にしません (デフォルト: ベンチマークでは無効)。

### `--turbo`

ターボブーストを無効にしません (デフォルト: ベンチマークでは無効)。

### `--numa-balancing`

自動 NUMA バランシングを無効にしません (デフォルト: ベンチマークでは無効)。

### `--timer-migration`

タイマーマイグレーションを無効にしません (デフォルト: ベンチマークでは無効)。

### `--soft-watchdog`

ソフトロックアップウォッチドッグを無効にしません (デフォルト: ベンチマークでは無効)。

### `--ksm`

KSM (Kernel Samepage Merging) を無効にしません (デフォルト: ベンチマークでは無効)。

### `--cstates`

深い C ステートを無効にしません (デフォルト: ベンチマークでは無効)。

### `--no-irq-steering`

デバイスの IRQ とカーネルのワークキューをハウスキーピングコアに振り向けません。

### `--no-cpuset-partition`

分離された cpuset パーティションによってベンチマークコアをスケジューラーから切り離しません。

### `--swappiness <SWAPPINESS>`

swappiness の値を設定します。
デフォルトでは `10` が使用されます。

### `--governor <GOVERNOR>`

CPU スケーリングガバナーを設定します。
デフォルトでは `performance` が使用されます。

### `--perf-event-paranoid <PERF_EVENT_PARANOID>`

`perf_event_paranoid` の値を設定します。
デフォルトでは `-1` が使用されます。

### `--thp <THP>`

ホストの Transparent Hugepage モードを `never`、`madvise`、`always`、`leave` のいずれかに設定します。
`leave` を指定すると、ホストの現在のモードを維持します。
デフォルトでは `never` が使用されます。
