### `--detach`

<br />

[베어 메탈 Job][job]을 제출한 후 완료를 기다리지 않고 분리합니다.
[`--github-actions` 옵션][github actions]을 사용하면 Job이 끝날 때 Bencher가 프로젝트의 [연결된 저장소][linked repository]에 GitHub Check와 pull request 댓글을 게시합니다.
Job이 끝날 때 다른 요청을 보내려면 [`--callback-url` 옵션][callback url]을 사용하세요.
이 옵션은 [`--image` 옵션][image]이 설정되어 있어야 합니다.
이 옵션은 [`--job-poll-interval` 옵션][job poll interval] 및 [`--error-on-alert` 플래그][error on alert]와 충돌합니다.
분리된 실행은 보고서가 생기기 전에 종료되며, `--github-actions`를 사용하면 경고가 GitHub Check를 실패시킵니다.
