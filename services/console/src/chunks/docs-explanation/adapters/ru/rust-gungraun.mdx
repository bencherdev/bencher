## 🦀 Rust Gungraun

Адаптер Rust Gungraun (`rust_gungraun`) ожидает вывод [Gungraun](https://github.com/gungraun/gungraun).
Для наиболее полных результатов включите вывод JSON-сводок Gungraun (то есть `GUNGRAUN_OUTPUT_FORMAT=json`),
которые адаптер читает раньше текстового вывода.
Читаются схемы сводок 6 и 7.

Из JSON-сводок каждый Бенчмарк называется по пути своего модуля, а его `id` становится Параметром `@id`.
Из текстового вывода каждый Бенчмарк называется по всей своей первой строке.
Поэтому два формата дают одному и тому же бенчмарку разные имена: выберите один и придерживайтесь его.
Каждый инструмент, который запускает бенчмарк (например, `callgrind`, `cachegrind` или `dhat`), является отдельным Вариантом с Параметром `@tool`.
Раздел текстового вывода без заголовка инструмента относится к `callgrind`.

Измерения `instructions`, `l1-hits`, `l2-hits`, `ram-hits`, `total-read-write` и `estimated-cycles` собираются по умолчанию.
Каждый другой счетчик, который сообщают Callgrind, Cachegrind, DHAT, Memcheck, Helgrind или DRD, также собирается как отдельное Измерение.
Каждый счетчик является точным счетом и собирается как одна Метрика `value`, для которой и стоит в первую очередь задать Порог.
Событие `perf` собирается как `mean` его замеров или как одно `value`, и именно для этой Метрики в первую очередь задается Порог.
Схема 7 также собирает время работы каждого инструмента как Измерение `profile-time` (то есть `nanoseconds (ns)`).
Время, проведенное в системных вызовах, пропускается, поскольку вывод не указывает его единицу.
Измерения этого адаптера не создаются по умолчанию для всех проектов.
Однако при использовании этого адаптера эти Измерения будут автоматически созданы для вашего Проекта.

Gungraun является переименованным преемником Iai-Callgrind.
