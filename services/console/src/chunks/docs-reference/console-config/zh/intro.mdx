Bencher 控制台 UI 不需要任何配置。
但是，可以通过以下环境变量自定义一些默认设置以满足你的需求：

- `BENCHER_API_URL`：用于访问 [Bencher API 服务器][server config] 的 URL。控制台服务器会将浏览器的每个请求，经由控制台自身 URL 下的 `/api`，中继到该 URL。默认值为 `http://localhost:6610`。
- `INTERNAL_API_URL`：控制台服务器通过另一个地址访问 API 服务器时，用来代替 `BENCHER_API_URL` 进行中继的 URL。[Docker Compose][docker compose] 会将其设置为 `http://bencher_api:6610`，即两者共享的 Docker 网络上 API 服务器的容器；当 `BENCHER_API_URL` 未设置或指向回环地址（例如 `localhost`）时，[`bencher up`][bencher up] 也会这样设置。否则，默认情况下未设置。
- `BENCHER_RELAY_SECRET`：控制台服务器与 [API 服务器的 `security.relay_secret`][security] 共享的密钥。在两台服务器上设置相同的值后，API 服务器会信任控制台服务器中继的浏览器 IP 地址，并且只在控制台服务器中继的请求上接受会话。默认情况下未设置。
- `OAUTH_GITHUB`：设置为 `true` 可使用 [自托管的 GitHub 应用][github app] 启用 `Login with GitHub`。这需要 [Bencher Plus 企业版计划][bencher plus enterprise]。默认情况下未设置。
- `OAUTH_GOOGLE`：设置为 `true` 可使用 [自托管的 Google OAuth2][google oauth2] 启用 `Login with Google`。这需要 [Bencher Plus 企业版计划][bencher plus enterprise]。默认情况下未设置。
