## `--threshold-measure <MEASURE>`

<br />

Используйте указанное имя, слаг или UUID [Измерения][measure] для порога.
Если указанное значение представляет собой имя или слаг и Измерение еще не существует, оно будет создано для вас.
Однако, если указанное значение является UUID, то Измерение уже должно существовать.

Например, чтобы использовать порог для Измерения Latency,
вы могли бы написать `--threshold-measure latency`.
Используйте его вместе с [опцией `--threshold-metric`](#--threshold-metric-metric), чтобы указать Метрику Измерения, которую проверяет порог.

[measure]: /ru/docs/explanation/benchmarking/#measure
