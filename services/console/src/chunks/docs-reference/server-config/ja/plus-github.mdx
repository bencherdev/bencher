### `plus.github`

このセクションでは、[OAuth2認証に使用されるGitHubアプリ](/ja/docs/how-to/github-app/)の設定を指定します。
サーバー上の少なくとも1つの組織に対して有効なBencher Plus _エンタープライズ_ ライセンスが必要です。
このセクション全体はオプションです。
指定しない場合、GitHubによる認証は有効になりません。

|     名前      |                   例                    | デフォルト | 必須  |                                                                                                                                                                                説明                                                                                                                                                                                |
| :-----------: | :-------------------------------------: | :--------: | :---: | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|   client_id   |          Iv1.12864abcd1232048           |    ---     | はい  | GitHub AppのクライアントIDを指定します。クライアントIDはアプリIDとは異なります。クライアントIDはアプリの設定ページで確認できます。GitHub Appの設定ページへの移動についての詳細は、[GitHub Appの登録の変更](https://docs.github.com/ja/apps/maintaining-github-apps/modifying-a-github-app-registration#navigating-to-your-github-app-settings)を参照してください。 |
| client_secret | 00000abcd12345wxyz123456789abcdefgh0000 |    ---     | はい  |                                                                                                                   この項目では、GitHubアプリのクライアントシークレットを指定します。クライアントシークレットはアプリの設定ページで生成できます。                                                                                                                   |
|        app         |                \{ ... \}                |   ---   |   いいえ   | プロジェクトにリンクされたリポジトリのdispatchトークンを発行するGitHub Appを指定します。`client_id`で指定したものと同じGitHub Appである必要があります。アプリにはリポジトリのコンテンツへの読み取りと書き込みのアクセスが必要です。指定しない場合、どのプロジェクトもリポジトリをリンクできません。 |
|      app.slug      |             my-bencher-app              |   ---   |   はい   | URL に含まれる GitHub App の名前です (`https://github.com/apps/my-bencher-app` など)。ユーザーがアプリをインストールするページを示します。 |
|  app.private_key   | "-----BEGIN RSA PRIVATE KEY-----\n..." |   ---   |   はい   | GitHub AppのPEM形式の秘密鍵です。秘密鍵はアプリの設定ページで生成できます。 |
| app.webhook_secret |    0123456789abcdef0123456789abcdef     |   ---   |   はい   | GitHub AppのWebhookシークレットです。Webhookシークレットはアプリの設定ページで設定できます。 |
