### `plus.mcp`

Esta sección configura el [servidor MCP de Bencher](/es/docs/how-to/mcp/).
Toda la sección es opcional.

|        Nombre         |             Ejemplo              | Predeterminado | Requerido |                                                                                                Descripción                                                                                                 |
| :-------------------: | :------------------------------: | :------------: | :-------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| openai_apps_challenge | a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6 |      ---       |    No     | El token de verificación de dominio que OpenAI emite cuando envías una aplicación que usa este servidor MCP. El servidor de la API lo sirve como texto plano en `/.well-known/openai-apps-challenge`. Si no se especifica, esa ruta devuelve `404 Not Found`. |
