## BMF Versions

У каждого Проекта есть версия BMF, и новый Проект начинается с версии 1.
Отчет читается в версии, которую он объявляет в своем поле `bmf_version`, а иначе в версии своего Проекта.
Подкоманда CLI <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code> считывает версию Проекта и объявляет ее в каждом Отчете.
Проект, которого еще не существует, читается как версия 1, так как запуск создает его в версии 1.

Объявленная версия является контрактом.
Результаты, которые разбираются в другой версии, получают `400 Bad Request`,
где названы обе версии, сказано, откуда взялась ожидаемая версия, и перечислены способы это исправить.

[Адаптер `json`][json adapter] читает JSON в версии Отчета.
Адаптеры `json_v0` и `json_v1` читают JSON каждый в своей версии,
и `bencher run --adapter json_v0` или `--adapter json_v1` объявляет эту версию в любом Проекте.

Пользователь, который может редактировать Проект, переводит его с версии 0 на версию 1
с помощью `bencher project update --bmf-version 1`, API или кнопки Move to version 1 в настройках Проекта.
Только администратор сервера может вернуть Проект на версию 0.

<summary>BMF версия 0</summary>

BMF версии 0 является более ранней версией, которую по-прежнему используют Проекты версии 0.
Она сопоставляет имя каждого Бенчмарка с его Измерениями, а каждое Измерение с тройкой Метрики:

<BmfV0Example />

В версии 0 у Бенчмарка нет Параметров, поэтому у него один Вариант.
Измерение содержит `value`, которое обязательно, а также `lower_value` и `upper_value`, которые необязательны.
Версия 0 читает только эти три имени: любое другое имя в Измерении игнорируется без замечания.
