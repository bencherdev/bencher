## 🕸 JavaScript Deno

JavaScript Deno アダプター（`js_deno`）は、JSON 形式（つまり `--json`）の [`deno bench`](https://docs.deno.com/runtime/reference/cli/bench/) の出力を想定しています。
アダプターが読み取るのが JSON だけになるように、ベンチマークファイルのトップレベルからは何も出力しないでください。

<DenoBench />

各ベンチマークは、JSON 出力内のすべてのファイルに共通するディレクトリからの相対パスで表したファイル、
グループ（ある場合）、名前を ` > ` で連結した名前になります。
例えば、`sub/deep_bench.ts > noop` です。
パラメータはありません。
`latency` メジャー（つまり `nanoseconds (ns)`）は次のメトリックで収集されます:
- `mean`、`min`、`max`
- `p75`、`p99`、`p99_5`、`p99_9`: 75、99、99.5、99.9 パーセンタイル

Deno は中央値を報告しないため、まず `mean` メトリックにしきい値を設定してください（`--threshold-metric mean`）。
失敗したベンチマークは、レポートの警告でスキップとして数えられます。
二つのベンチマークが同じ名前を持つ場合、Deno は両方を最初の名前の下に報告するため、最初の結果のみが保持され、もう一方はスキップとして数えられます。
Deno の JSON 形式のバージョン 1 のみが読み取られます。

JavaScript Deno アダプターは BMF バージョン 1 の結果のみを読み取ります。
BMF バージョン 0 のプロジェクトのレポートは、プロジェクトを BMF バージョン 1 に移行する方法を示すエラーで拒否されます。
