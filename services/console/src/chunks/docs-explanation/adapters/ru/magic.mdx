## 🪄 Magic <small>(default)</small>

Адаптер Magic (`magic`) является надмножеством всех остальных адаптеров.
Поэтому он является адаптером по умолчанию для `bencher run`.
Однако адаптер `magic` следует использовать только для ознакомления.

В BMF версии 1 адаптер `magic` сначала пробует [адаптер `json`](#-json),
затем каждый адаптер оболочки в порядке приведенного ниже списка,
причем структурированный вывод оболочки читается раньше ее текстового вывода.
Используется первый адаптер, который прочитал хоть какие-то результаты,
поэтому запускайте только одну оболочку бенчмаркинга за один `bencher run`.
Данные в BMF версии 0 для Проекта с BMF версией 1 отклоняются с ошибкой, в которой названы обе версии.
