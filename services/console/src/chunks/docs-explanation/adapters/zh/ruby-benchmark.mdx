## ♦️ Ruby Benchmark

Ruby Benchmark 适配器（`ruby_benchmark`）接受 `#bm`、`#bmbm` 和 `#benchmark` 方法的 [Benchmark 模块](https://github.com/ruby/benchmark) 输出。
每个基准测试都需要一个标签。
每个基准测试以其标签命名，没有参数。
收集以下度量，每个都只有一个指标 `value`，即 Ruby 在该列中打印的时间。
- `latency`（即 `nanoseconds (ns)`）：`real` 时间
- `user-time`（即 `nanoseconds (ns)`）：`user` 时间
- `system-time`（即 `nanoseconds (ns)`）：`system` 时间
- `cpu-time`（即 `nanoseconds (ns)`）：`total` 时间

请首先为 `value` 指标设置阈值，使用 `--threshold-metric value`。

输出会被尽力读取。
Ruby 先打印一行的标签，再运行其代码块，然后打印其时间，
因此会打印内容的代码块会把该行拆开：该行会在报告的警告中计为已跳过，其后的行仍会被读取。
请在基准测试内部打印到 `stderr`，以保留每一行。
