## `--threshold-parameters <PARAMETERS>`

<br />

지정된 매개변수 필터를 JSON 객체로 임계값에 사용하십시오(예: `--threshold-parameters '{"size": 512}'`).
임계값은 객체의 각 키를 같은 값으로 가진 매개변수를 갖는 모든 [변형(Variant)][variant]을 검사하므로,
`{"size": 512}`는 `{"op": "read", "size": 512}`와 `{"op": "write", "size": 512}` 모두와 일치합니다.
값은 JSON이며, pull request 댓글과 콘솔이 보여주는 `size=512` 형식이 아닙니다.
설정하지 않거나 `{}`로 설정하면 임계값은 모든 변형을 검사합니다.
특정 임계값에 대해 이 옵션을 무시하려면 언더스코어(`_`)를 사용하세요.
매개변수 필터가 있는 임계값에는 [`--threshold-metric` 옵션](#--threshold-metric-metric)도 필요합니다.
BMF 버전 0에서는 `--threshold-parameters`가 무언가를 전송하기 전에 오류와 함께 `bencher run`을 중지시킵니다.

각 `--threshold-parameters` 옵션은 매개변수 한 세트를 담습니다.
여러 세트 중 하나와 일치하는 변형을 검사하려면 API를 사용하세요.
BMF 버전 1에서 보고서의 `thresholds`는 각 임계값을 세트 목록 형태의 `parameters` 필터와 함께 나열합니다.
