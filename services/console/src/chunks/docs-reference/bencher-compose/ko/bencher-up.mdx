## `bencher up`

Bencher 셀프 호스티드 컨테이너를 생성하고 시작합니다.
이는 [`docker compose up`][docker compose up]을 실행하는 것과 유사합니다.

두 컨테이너는 `bencher`라는 Docker 네트워크에 참여하며, `bencher up`은 이 네트워크를 생성하거나 이전 실행에서 남은 것이 있으면 재사용합니다.
자신이 생성하지 않은 `bencher` 네트워크가 있으면 오류와 함께 중단하며, `bencher up console`은 아직 네트워크에 없는 실행 중인 `bencher_api` 컨테이너를 연결합니다.
Console 서버의 `BENCHER_API_URL`이 설정되지 않았거나 `localhost`와 같은 루프백 주소를 가리키면, Console 서버는 그곳에서 API 서버 컨테이너로 중계합니다. [`--console-env` 옵션][console env]으로 설정하지 않는 한, `INTERNAL_API_URL`은 `http://bencher_api:6610`입니다.
그렇지 않으면 `BENCHER_API_URL`로 중계합니다.
