### `--measure <MEASURE>`

<br />

Opcional: Conservar de los resultados solo el nombre, slug o UUID de la [Medida][measure] especificada.
Todas las demás Medidas se descartan antes de almacenar nada.
Se pueden conservar varias Medidas usando la opción `--measure` varias veces.
Solo se conservan las primeras `64`, y el Informe advierte del resto.
Una Medida que los resultados no contienen se ignora.
Si no se establece, se conservan todas las Medidas.

[measure]: /es/docs/explanation/benchmarking/#measure
