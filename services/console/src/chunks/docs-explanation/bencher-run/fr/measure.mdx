### `--measure <MEASURE>`

<br />

Optionnel : Ne conserver des résultats que le nom, le slug ou l'UUID de la [Mesure][measure] spécifiée.
Toutes les autres Mesures sont écartées avant que quoi que ce soit ne soit enregistré.
Plusieurs Mesures peuvent être conservées en utilisant l'option `--measure` plusieurs fois.
Seules les `64` premières sont conservées, et le Rapport avertit pour le reste.
Une Mesure que les résultats ne contiennent pas est ignorée.
Si elle n'est pas définie, toutes les Mesures sont conservées.

[measure]: /fr/docs/explanation/benchmarking/#measure
