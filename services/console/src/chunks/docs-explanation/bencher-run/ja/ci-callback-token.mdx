### `--ci-callback-token <TOKEN>`

<br />

オプション: デタッチした[ベアメタルJob][job]のコールバックで使用する認証トークンを設定します。

[`--detach`フラグ][detach]と[`--github-actions`オプション](#--github-actions-github_token)を使用する場合、
このオプションには、そのリポジトリに対して少なくとも`contents: write`権限を持つ[Fine-grained personal access token][github fine-grained token]を設定してください。
これにより、Bencher APIサーバーはそのトークンを使用して[`repository_dispatch`][github repository dispatch]ワークフローをトリガーできます。
全体を把握するために[GitHub Actionsでのベアメタル上のプルリクエスト][pull requests on bare metal]を参照してください。

> 🐰 `GITHUB_TOKEN`は現在のワークフローが終了するとすぐに期限切れになるため、ここで`GITHUB_TOKEN`をそのまま使用することはできません！
