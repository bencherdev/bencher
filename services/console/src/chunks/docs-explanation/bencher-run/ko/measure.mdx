### `--measure <MEASURE>`

<br />

선택사항: 결과에서 지정된 [측정][measure] 이름, 슬러그 또는 UUID만 유지합니다.
그 외의 모든 측정은 저장되기 전에 제외됩니다.
`--measure` 옵션을 여러 번 사용하여 여러 측정을 유지할 수 있습니다.
처음 `64`개만 유지되며, 나머지는 보고서가 warning으로 알립니다.
결과에 포함되지 않은 측정은 무시됩니다.
설정하지 않으면 모든 측정이 유지됩니다.

[measure]: /ko/docs/explanation/benchmarking/#measure
