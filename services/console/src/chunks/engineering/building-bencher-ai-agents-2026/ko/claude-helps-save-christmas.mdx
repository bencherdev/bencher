## Claude, 크리스마스를 구하다

많은 사람들처럼, 저도 2025년 겨울 휴가 동안 Claude Opus 4.5를 제대로 써 볼 기회가 있었습니다. 저는 아내와 아이를 데리고 런던에 사는 여동생 가족을 방문하고 있었습니다. 여동생이 얼마 전 쌍둥이를 낳아서 저는 일손을 거들러 간 것이었죠. 그런데 정작 저는 위층에 틀어박혀 Bencher를 노린 이메일 스팸과 DDoS 공격을 막아 내느라 씨름하고 있었습니다. Claude는 무슨 일이 일어나고 있는지 진단하고 가능한 해결책을 떠올리는 데 정말 큰 도움이 됐습니다.

결국 저는 Bencher를 Cloudflare 뒤로 옮기고 reCAPTCHA를 설정했습니다. 대부분의 작업은 여전히 제가 했지만, 서로 충돌하는 여러 설계 제약 조건 속에서 문제를 해결하는 능력은 Opus 4.5에서 눈에 띄게 향상되어 있었습니다. 다만, Claude가 제안한 변경 하나 때문에 [Bencher CLI를 설치하는 편의 스크립트][bencher install cli]가 반나절 동안 먹통이 되기도 했습니다. 이런.
