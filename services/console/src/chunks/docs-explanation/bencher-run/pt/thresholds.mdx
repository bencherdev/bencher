<br />

Na versão 1 do BMF, um Limiar verifica uma Métrica de uma Medida, que `--threshold-metric` nomeia.
Um `--threshold-measure` sem nenhum `--threshold-metric` não define nenhum Limiar:
a execução ainda é registrada, e seu Relatório avisa que o Limiar foi ignorado, com uma dica para usar `--threshold-metric`.
