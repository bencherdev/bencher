## 🕸 JavaScript Deno

Адаптер JavaScript Deno (`js_deno`) ожидает вывод [`deno bench`](https://docs.deno.com/runtime/reference/cli/bench/) в формате JSON (то есть `--json`).
Ничего не печатайте с верхнего уровня файла бенчмарков, чтобы адаптер читал только JSON.

<DenoBench />

Каждый Бенчмарк называется по своему файлу относительно общего каталога всех файлов в JSON-выводе,
затем по своей группе (если она есть) и имени, соединенным через ` > `.
Например, `sub/deep_bench.ts > noop`.
Параметров нет.
Измерение `latency` (то есть `nanoseconds (ns)`) собирается со следующими Метриками:
- `mean`, `min` и `max`
- `p75`, `p99`, `p99_5` и `p99_9`: 75-й, 99-й, 99.5-й и 99.9-й перцентили

Deno не сообщает медиану, поэтому в первую очередь задайте Порог для Метрики `mean` с помощью `--threshold-metric mean`.
Бенчмарк, который упал, учитывается как пропущенный в замечаниях Отчета.
Если у двух бенчмарков одинаковое имя, Deno сообщает оба под первым, поэтому сохраняется только первый результат, а другой учитывается как пропущенный.
Читается только версия 1 формата JSON Deno.

Адаптер JavaScript Deno читает результаты только в BMF версии 1.
Отчет для Проекта с BMF версией 0 отклоняется с ошибкой, в которой сказано, как перевести Проект на BMF версию 1.
