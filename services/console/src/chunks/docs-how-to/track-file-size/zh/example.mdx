在此示例中，键 `my_binary` 是二进制文件名。它被用作[基准测试][benchmark]的名称。`my_binary` 键对应一个只有一个条目的列表，该条目的 `measures` 对象包含 `file-size` 键。`file-size` 是内置 File Size [度量][measure]的 slug。File Size 度量默认不为所有项目创建。然而，当你使用 File Size 度量时，它将自动为你的项目创建。File Size 度量对象包含 `value` [指标][metric]，即以字节为单位的文件大小 `42.0`。

文件大小总是以整字节增量计算。
也就是说，它 _绝不会_ 有像 `42.5` 这样的十进制数。
但是，BMF JSON 需要支持各种可能的值，所以它使用浮点数而不是整数。
