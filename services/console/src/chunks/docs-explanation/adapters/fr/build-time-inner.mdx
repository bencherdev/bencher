### ⏱️ Build Time

La sous-commande CLI <code><a href="/fr/docs/explanation/bencher-run/">bencher run</a></code>
peut être utilisée pour suivre le temps de build (c.-à-d. le temps de compilation) de vos livrables avec le drapeau `--build-time`.
En coulisses, <code><a href="/fr/docs/explanation/bencher-run/">bencher run</a></code>
produit les résultats en [Bencher Metric Format (BMF) JSON][bmf] dans la version de BMF du Projet.
C'est donc une bonne pratique d'utiliser explicitement [l'adaptateur `json`][json].
Pour plus de détails, voir [comment suivre le temps de build][build time].

La Mesure `build-time` (c.-à-d. `seconds (s)`) est recueillie comme une seule Métrique `value`,
qui est la Métrique sur laquelle placer un Seuil en premier.
La Mesure `build-time` n'est pas créée par défaut pour tous les Projets.
Cependant, lorsque vous utilisez le drapeau `--build-time`, cette Mesure sera automatiquement créée pour votre Projet.
