### Parameters
Параметры являются входными данными, с которыми был запущен Бенчмарк, например `{"size": 64}`.
Каждый ключ соответствует строке, числу или логическому значению, а Параметры Бенчмарка содержат не более `8` ключей.
Бенчмарк с одним набором Параметров является Вариантом,
поэтому у Бенчмарка, который запускается с несколькими наборами Параметров, есть по одному Варианту для каждого набора,
и Bencher отслеживает Метрики каждого Варианта отдельно.
У Бенчмарка без Параметров есть единственный Вариант с пустыми Параметрами.

Параметры являются частью [Bencher Metric Format (BMF)][bmf] версии 1,
и [адаптер оболочки бенчмаркинга][adapters] считывает их из вашей оболочки бенчмаркинга, где это возможно.
