## Claude、クリスマスを救うのに一役買う

多くの人と同じように、2025年の冬休みに私はClaude Opus 4.5をじっくり使う機会がありました。私は妻と子どもと一緒に、ロンドンにいる妹の家族を訪ねていました。妹は双子を出産したばかりだったので、私は手伝いに行っていたはずでした。ところが実際には、2階にこもって、Bencherに対するスパムメールやDDoS攻撃と戦っていたのです。何が起きているのかを診断し、解決策のアイデアを出すうえで、Claudeは非常に頼りになりました。

最終的に、BencherをCloudflareの背後に移行し、reCAPTCHAを導入しました。作業の大部分はまだ私自身がやっていましたが、多くの相反する設計上の制約をまたいで問題を解決する能力において、Opus 4.5ははっきりと一段上でした。とはいえ、Opus 4.5が提案した変更のせいで、[Bencher CLIをインストールするための便利スクリプト][bencher install cli]が半日ほど使えなくなったこともありました。おっと。

[bencher install cli]: /ja/docs/how-to/install-cli/#install-cli-with-script
