### `--ci-callback-token <TOKEN>`

<br />

선택 사항: 분리된 [베어 메탈 Job][job]의 콜백에 사용할 인증 토큰을 설정합니다.

[`--detach` 플래그][detach]와 [`--github-actions` 옵션](#--github-actions-github_token)을 사용할 때는,
Job이 끝나면 Bencher API 서버가 [`repository_dispatch`][github repository dispatch] 워크플로를 트리거합니다.
[연결된 저장소][pull requests on bare metal]가 있는 프로젝트는 Bencher가 토큰을 만들므로 이 옵션이 필요하지 않습니다.
대신 자체 토큰을 사용하려면, 이 옵션을 해당 저장소에 대해 최소한 `contents: write` 권한을 가진
[fine-grained personal access token][github fine-grained token]으로 설정합니다.
그러면 Bencher는 프로젝트에 연결된 저장소가 있든 없든 이 토큰으로 `repository_dispatch` 이벤트를 보냅니다.
CLI는 GitHub Enterprise Server와 `v0.6.16` 이전의 Bencher API 서버에서 이 옵션을 요구합니다.
이 옵션이 없으면 서버에 GitHub 앱이 없거나, 프로젝트에 연결된 저장소가 없거나, 연결된 저장소의 연결이 끊어진 경우 `claimed` 프로젝트의 분리된 실행이 거부됩니다.
전체 개요는 [GitHub Actions의 베어 메탈에서의 Pull Requests][pull requests on bare metal]를 참조하세요.

> 🐰 `GITHUB_TOKEN`은 현재 워크플로가 끝나는 즉시 만료되므로 여기에 그대로 사용할 수 없습니다!
