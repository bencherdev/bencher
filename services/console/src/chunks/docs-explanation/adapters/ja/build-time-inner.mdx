### ⏱️ Build Time

<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code> CLI サブコマンドは、
`--build-time` フラグを使用して、成果物のビルド時間（つまりコンパイル時間）を追跡するために使用できます。
内部的には、<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code> は、
結果をプロジェクトの BMF バージョンの [Bencher Metric Format (BMF) JSON][bmf] として出力します。
そのため、明示的に [`json` アダプター][json]を使用することをお勧めします。
詳細については、[ビルド時間を追跡する方法][build time]を参照してください。

`build-time` メジャー（つまり `seconds (s)`）は単一の `value` メトリックとして収集され、
これが最初にしきい値を設定するメトリックです。
`build-time` メジャーは、すべてのプロジェクトにデフォルトで作成されるわけではありません。
ただし、`--build-time` フラグを使用すると、このメジャーはプロジェクトに自動的に作成されます。
