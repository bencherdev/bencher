## ♦️ Ruby Benchmark

Адаптер Ruby Benchmark (`ruby_benchmark`) ожидает вывод [модуля Benchmark](https://github.com/ruby/benchmark) для методов `#bm`, `#bmbm` и `#benchmark`.
Для каждого бенчмарка нужна метка.
Каждый Бенчмарк называется по своей метке, без Параметров.
Собираются следующие Измерения, каждое с одной Метрикой `value`, то есть временем, которое Ruby печатает в этом столбце.
- `latency` (то есть `nanoseconds (ns)`): время `real`
- `user-time` (то есть `nanoseconds (ns)`): время `user`
- `system-time` (то есть `nanoseconds (ns)`): время `system`
- `cpu-time` (то есть `nanoseconds (ns)`): время `total`

В первую очередь задайте Порог для Метрики `value` с помощью `--threshold-metric value`.

Вывод читается по мере возможности.
Ruby печатает метку строки, выполняет ее блок, а затем печатает ее время,
поэтому блок, который что-то печатает, разрывает свою строку: эта строка учитывается как пропущенная в замечаниях Отчета, а строки после нее по-прежнему читаются.
Печатайте в `stderr` изнутри бенчмарка, чтобы сохранить каждую строку.
