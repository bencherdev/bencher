<br />

En la versión 1 de BMF, un Umbral comprueba una Métrica de una Medida, que `--threshold-metric` nombra.
Un `--threshold-measure` sin ningún `--threshold-metric` no establece ningún Umbral:
la ejecución se registra igualmente, y su Informe advierte que el Umbral se omitió, con una sugerencia para usar `--threshold-metric`.

Consulta [umbrales y alertas](/es/docs/explanation/thresholds/) para una descripción completa.
