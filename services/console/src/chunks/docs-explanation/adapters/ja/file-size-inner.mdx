### ⚖️ File Size

<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code> CLI サブコマンドは、
`--file-size` オプションを使用して、成果物のファイルサイズ（つまりバイナリサイズ）を追跡するために使用できます。
`--file-size` オプションには、サイズを測定するファイルのファイルパスを指定します。
内部的には、<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code> は、
結果をプロジェクトの BMF バージョンの [Bencher Metric Format (BMF) JSON][bmf] として出力します。
そのため、明示的に [`json` アダプター][json]を使用することをお勧めします。
詳細については、[ファイルサイズを追跡する方法][file size]を参照してください。

`file-size` メジャー（つまり `bytes (B)`）は単一の `value` メトリックとして収集され、
これが最初にしきい値を設定するメトリックです。
`file-size` メジャーは、すべてのプロジェクトにデフォルトで作成されるわけではありません。
ただし、`--file-size` オプションを使用すると、このメジャーはプロジェクトに自動的に作成されます。
`--file-size` オプションを複数回使用して、複数のファイルサイズを追跡できます。
