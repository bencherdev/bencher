## 🪄 Magic <small>(default)</small>

The Magic Adapter (`magic`) is a superset of all other adapters.
For that reason, it is the default adapter for `bencher run`.
However, the `magic` adapter should be used for exploration only.

At BMF version 1, the `magic` adapter first tries [the `json` adapter](#-json),
then each harness adapter in the order of the list below,
reading a harness's structured output before its text output.
The first adapter that reads any results is used,
so run only one benchmark harness per `bencher run`.
A BMF version 0 payload for a Project at BMF version 1 is refused with an error that names both versions.
