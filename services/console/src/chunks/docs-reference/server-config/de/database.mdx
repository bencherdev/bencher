## `database`

|             Name             |                                   Beispiel                                    |              Standard              |              Erforderlich              |                                                                                                 Beschreibung                                                                                                  |
| :--------------------------: | :---------------------------------------------------------------------------: | :--------------------------------: | :------------------------------------: | :-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|             file             |                             "pfad/zu/database.db"                             | "/var/lib/bencher/data/bencher.db" |                   Ja                   |                                                                               Legt fest, wo die Serverdatenbank hingehen soll.                                                                                |
|         busy_timeout         |                                     5000                                      |                5000                |                  Nein                  |                                                Gibt den Busy-Timeout für die Datenbank in Millisekunden an. Verhindert sofortige SQLITE_BUSY-Fehler bei Sperrkonflikten.                                                |
|          cache_size          |                                     65536                                     |               65536                |                  Nein                  |                     Gibt die Seiten-Cache-Größe in KiB für die Schreibverbindung der Datenbank an. Ein größerer Cache vermeidet das erneute Lesen verdrängter Seiten bei großen Report-Importen und -Löschungen. Muss größer als 0 sein. |
