## 🕸 JavaScript Benchmark

O Adaptador JavaScript Benchmark (`js_benchmark`) espera a saída do [Benchmark.js](https://github.com/bestiejs/benchmark.js).
Cada Benchmark é nomeado como o Benchmark.js o imprime, sem Parâmetros.
A Medida `throughput` (ou seja, `operations / second (ops/s)`) é coletada com estas Métricas:
- `mean`: a taxa que o Benchmark.js imprime
- `mean_ci95_lower` e `mean_ci95_upper`: o intervalo de confiança de 95%, a partir da margem de erro relativa que o Benchmark.js imprime ao lado da taxa

Um Benchmark de uma única execução tem apenas sua `mean`.
Defina primeiro um Limiar para a Métrica `mean`, com `--threshold-metric mean`.
