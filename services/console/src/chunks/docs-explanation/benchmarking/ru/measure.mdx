### Measure
Измерение является единицей измерения для метрики.
По умолчанию во всех проектах создаются измерения `Latency` и `Throughput` с единицами `nanoseconds (ns)` и `operations / second (ops/s)` соответственно.
[Адаптер запуска бенчмарков][adapters] записывает каждое Измерение, о котором сообщает ваш инструмент для бенчмарков,
а [опция `--measure`][measure option] команды `bencher run` оставляет только перечисленные в ней Измерения.

Если вы используете [Bencher Metric Format (BMF)][bmf], имя, slug или UUID могут использоваться для идентификации измерения.
