La interfaz de Bencher Console no requiere ninguna configuración.
Sin embargo, algunos valores predeterminados se pueden personalizar para adaptarse a sus necesidades mediante las siguientes variables de entorno:

- `BENCHER_API_URL`: La URL del servidor de la API de Bencher ([the Bencher API server][server config]).
  El servidor de la Consola reenvía a ella cada solicitud del navegador, bajo `/api` en la propia URL de la Consola.
  Por defecto, esto está establecido en `http://localhost:6610`.
- `INTERNAL_API_URL`: La URL a la que el servidor de la Consola reenvía en lugar de `BENCHER_API_URL`,
  cuando llega al servidor de la API por otra dirección.
  [Docker Compose][docker compose] la establece en `http://bencher_api:6610`,
  el contenedor del servidor de la API en la red de Docker que ambos comparten,
  y también [`bencher up`][bencher up] cuando `BENCHER_API_URL` no está configurado o nombra una dirección de loopback, como `localhost`.
  De lo contrario, de forma predeterminada, no está configurado.
- `BENCHER_RELAY_SECRET`: El secreto que el servidor de la Consola comparte con [el `security.relay_secret` del servidor de la API][security].
  Con el mismo valor en ambos servidores, el servidor de la API confía en la dirección IP del navegador que reenvía el servidor de la Consola,
  y acepta una sesión solo en una solicitud que reenvía el servidor de la Consola.
  De forma predeterminada, no está configurado.
- `OAUTH_GITHUB`: Establézcalo en `true` para habilitar `Login with GitHub` usando un [GitHub App autohospedado][github app].
  Esto requiere un [plan Bencher Plus Enterprise][bencher plus enterprise]. De forma predeterminada, no está configurado.
- `OAUTH_GOOGLE`: Establézcalo en `true` para habilitar `Login with Google` usando un [OAuth2 de Google autohospedado][google oauth2].
  Esto requiere un [plan Bencher Plus Enterprise][bencher plus enterprise]. De forma predeterminada, no está configurado.
