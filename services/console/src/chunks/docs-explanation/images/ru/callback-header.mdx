### `--callback-header <NAME: VALUE>`

<br />

Необязательно: Добавляет заголовок к запросу callback в формате `NAME: VALUE`.
Максимальный размер `NAME` заголовка составляет 256 байт, а максимальный размер `VALUE` заголовка составляет 8 КиБ.
Эту опцию можно указать несколько раз (не более 16).

Следующие заголовки не поддерживаются:

- `Connection`
- `Content-Length`
- `Host`
- `Keep-Alive`
- `Proxy-Connection`
- `TE`
- `Trailer`
- `Transfer-Encoding`
- `Upgrade`

Эта опция требует, чтобы была задана [опция `--callback-url`](#--callback-url-url).
