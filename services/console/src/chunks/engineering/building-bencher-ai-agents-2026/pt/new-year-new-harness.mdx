## Ano Novo, Harness Novo

Em janeiro deste ano, eu já vinha ouvindo havia meses o quão impressionante o Claude Code era. Eu tinha adiado experimentá-lo porque o Opus 4 simplesmente não atingia o meu padrão de qualidade para que eu confiasse no seu trabalho. Agora que o Opus 4.5 tinha atingido esse padrão, eu quis experimentar o Claude Code também. O nível de melhoria que vi ao passar do Copilot como harness para o Claude Code foi um salto tão grande quanto passar do Opus 4/GPT-5.2/Gemini 2.5 Pro como modelo para o Opus 4.5.

No meu primeiro fim de semana com o Claude Code, fiz um teste não muito controlado contra o Copilot. Eu queria que o Copilot transformasse um PDF em um audiolivro. Mesmo no “Agent Mode”, o Copilot avançava cinco ou seis passos e então simplesmente parava até eu cutucá-lo de novo. Enquanto isso, o Claude Code estava trabalhando a todo vapor tentando construir um hipervisor personalizado, depois de passar por um Plan mode minucioso. Fiquei absolutamente convencido de que o nível de abstração tinha subido do modelo para o harness e de que o Copilot nunca mais ia conseguir alcançar.
