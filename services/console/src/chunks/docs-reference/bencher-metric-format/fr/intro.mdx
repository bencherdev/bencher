Les [adaptateurs de harnais de benchmark intégrés][adapters] convertissent la sortie de benchmark en format JSON de métriques Bencher (BMF).
Les harnais de benchmarking personnalisés devraient produire leurs résultats en JSON BMF
et utiliser [l'adaptateur `json`][json adapter].
Consultez [comment suivre des benchmarks personnalisés][custom benchmarks] pour un aperçu complet.
Pour générer des données JSON BMF factices, utilisez la sous-commande CLI <code><a href="/fr/docs/reference/bencher-metric-format/#bencher-mock">bencher mock</a></code>.

BMF a deux versions, et chaque Projet en a une.
La version 1 est le format avec lequel un nouveau Projet démarre, et c'est le format que décrit cette page.
La version 0 est la version précédente, que les Projets en version 0 utilisent encore.
Consultez [les versions de BMF](#bmf-versions) pour savoir comment la version d'un Rapport est choisie et pour la version 0.
