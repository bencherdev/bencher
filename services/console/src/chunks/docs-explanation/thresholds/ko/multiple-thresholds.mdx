## 여러 임계값

동일한 <code><a href="/ko/docs/explanation/bencher-run/">bencher run</a></code> 호출로 여러 임계값을 생성할 수 있습니다.
여러 임계값을 지정할 때에는 각 임계값에 대해 동일한 옵션을 사용해야 합니다.
특정 임계값에 대한 옵션을 무시하려면 언더스코어(`_`)를 사용하세요.
단, `--threshold-metric`은 예외입니다. 모든 임계값에는 각자의 메트릭이 필요하므로 언더스코어로 건너뛸 수 없습니다.

예를 들어, 두 개의 임계값만 사용하고 싶다면,
하나는 Latency 측정에 대한 것이고 하나는 Throughput 측정에 대한 것이라면,
Latency 측정에는 상위 경계를 설정하고
Throughput 측정에는 하위 경계를 설정하고 싶을 것입니다.
따라서 Latency 측정에는 `--threshold-lower-boundary _`을 사용하고,
Throughput 측정에는 `--threshold-upper-boundary _`을 사용합니다.

하나의 측정에도 메트릭이나 매개변수 필터가 다른 여러 임계값을 둘 수 있습니다.
예를 들어 Latency 측정의 `median`에 대한 임계값과 `p99`에 대한 임계값입니다.
변형(Variant)과 일치하는 모든 임계값이 그 변형을 검사합니다.
따라서 같은 메트릭에 대한 필터 없는 임계값과 필터가 있는 임계값은 둘 다 필터와 일치하는 변형을 검사하며,
같은 회귀에 대해 둘 다 경고를 생성합니다.
같은 호출에서 두 번 지정된 임계값은 하나의 임계값이며,
그 모델은 마지막으로 지정된 것을 따릅니다.
