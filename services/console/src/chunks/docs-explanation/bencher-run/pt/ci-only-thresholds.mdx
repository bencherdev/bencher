### `--ci-only-thresholds`

<br />

Opcional: Somente publique resultados no CI se [um Limiar](/pt/docs/explanation/thresholds/) verificar uma Métrica do Relatório.
Se não existirem Limiares, nenhum comentário no pull request será publicado.
Todos os trabalhos de um Projeto em um pull request compartilham um único comentário, então o comentário é publicado se existir um Limiar para qualquer um de seus Relatórios.
Isso se aplica apenas aos comentários no pull request. A Verificação do GitHub é sempre criada.
Requer: `--github-actions`
