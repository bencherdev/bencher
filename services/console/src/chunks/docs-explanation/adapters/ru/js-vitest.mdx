## 🕸 JavaScript Vitest

Адаптер JavaScript Vitest (`js_vitest`) ожидает вывод [Vitest `bench`](https://vitest.dev/api/#bench) в формате JSON.
Этот JSON-вывод сохраняется в файл, поэтому вы должны использовать опцию `--file` команды CLI `bencher run`, чтобы указать путь к этому файлу.

Каждый Бенчмарк называется по своему файлу относительно общего каталога всех файлов в JSON-выводе,
затем по своим блокам `describe`, тесту, группе (если это не группа по умолчанию) и задаче, соединенным через ` > `.
Например, `sub/sort.bench.ts > sorting > arrays > normal`.
Запуск только части ваших файлов бенчмарков может изменить этот общий каталог, и тогда Бенчмарки переименуются.
Параметров нет.

И Измерение `latency` (то есть `nanoseconds (ns)`), и Измерение `throughput` (то есть `operations / second (ops/s)`) собираются со следующими Метриками:
- `mean`, `median`, `min` и `max`
- `p75`, `p99`, `p99_5` и `p99_9`: 75-й, 99-й, 99.5-й и 99.9-й перцентили
- `std_dev`, `std_err`, `median_abs_dev` и `mean_abs_dev`: стандартное отклонение, стандартная ошибка среднего, а также медианное и среднее абсолютные отклонения
- `mean_ci95_lower`, `mean_ci95_upper` и `mean_ci95_margin`: 95% доверительный интервал среднего и его погрешность

Для Vitest с 1 по 4 у Измерения `latency` есть статистики, которые содержит JSON-вывод,
а у Измерения `throughput` есть `mean` с `mean_ci95_lower` и `mean_ci95_upper`.
В первую очередь задайте Порог для Метрики `median` с помощью `--threshold-metric median`.
Если `median` нет, как у `throughput` в Vitest с 1 по 4 и у `latency` в Vitest 1, в первую очередь задайте Порог для `mean`.

Когда два проекта Vitest запускают один и тот же файл, JSON-вывод Vitest 5 содержит этот файл дважды под одним путем.
Сохраняется первая копия, а каждый повтор учитывается как пропущенный в замечаниях Отчета.
Передайте Vitest `--project`, чтобы запустить один проект.

Читается только формат `--outputJson` Vitest с 1 по 4.
Для Измерения `throughput` значения `lower_value` и `upper_value` находятся на величину относительной погрешности ниже и выше `value` соответственно.

Для Метрики `latency` есть два варианта:
- `mean` (по умолчанию): `lower_value` и `upper_value` находятся на одно стандартное отклонение ниже и выше среднего (то есть `value`) соответственно.
- `median`: доступна только медиана (то есть `value`). Ни `lower_value`, ни `upper_value` не собираются, так как Vitest не предоставляет межквартильный размах.

Это можно указать в подкоманде CLI <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code> с помощью опции `--average`.
