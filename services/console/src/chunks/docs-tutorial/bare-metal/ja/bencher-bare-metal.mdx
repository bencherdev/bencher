## Bencher Bare Metal

Bencher Bare Metal はベアメタルハードウェア上でベンチマークを実行し、ばらつきをなくして
より正確で信頼性の高いベンチマーク結果を提供します。
ベアメタルハードウェアなしで Bencher Cloud を使用することに興味がある場合は、[Bencher Cloud クイックスタートチュートリアル][quickstart]をチェックしてください。
このチュートリアルでは、Bencher Bare Metal を使い始めるためのセットアップを行います。
