### `plus.github`

此部分指定了用于 [OAuth2 认证的 GitHub 应用](/zh/docs/how-to/github-app/)的配置。
服务器上至少有一个组织必须拥有有效的 Bencher Plus _企业_ 许可证。
整个部分是可选的。
如果未指定，则不会启用与 GitHub 的认证。

| client_secret | 00000abcd12345wxyz123456789abcdefgh0000 |  ---   |    是    |                                                                                                                  您的 GitHub 应用的client secret。您可以在应用的设置页面上生成 client secret。                                                                                                                   |
