### ⚖️ File Size

El subcomando CLI <code><a href="/es/docs/explanation/bencher-run/">bencher run</a></code>
se puede usar para hacer seguimiento del tamaño de archivo (es decir, el tamaño del binario) de tus entregables con la opción `--file-size`.
La opción `--file-size` espera la ruta del archivo cuyo tamaño se medirá.
Internamente, <code><a href="/es/docs/explanation/bencher-run/">bencher run</a></code>
genera los resultados como [Bencher Metric Format (BMF) JSON][bmf] en la versión de BMF del Proyecto.
Por eso es una buena práctica usar explícitamente [el adaptador `json`][json].
Para más detalles, consulta [cómo hacer seguimiento del tamaño de archivo][file size].

La Medida `file-size` (es decir, `bytes (B)`) se recoge como una sola Métrica `value`,
que es la Métrica a la que poner un Umbral primero.
La Medida `file-size` no se crea por defecto para todos los Proyectos.
Sin embargo, cuando usas la opción `--file-size`, esta Medida se creará automáticamente para tu Proyecto.
La opción `--file-size` se puede usar varias veces para hacer seguimiento de varios tamaños de archivo.
