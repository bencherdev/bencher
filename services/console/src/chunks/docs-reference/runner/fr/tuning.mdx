### Réglage de l'hôte

Avant chaque benchmark, le `runner` applique un réglage de l'hôte pour réduire le bruit de mesure.
Par défaut, il désactive l'ASLR, le NMI watchdog, le SMT / hyper-threading et le turbo boost ;
règle le gouverneur de mise à l'échelle du CPU sur `performance`, la swappiness sur `10`, et `perf_event_paranoid` sur `-1`.
Sur un hôte que le `runner` n'a pas réglé depuis son dernier redémarrage, les drapeaux ci-dessous conservent au contraire les optimisations individuelles à leurs valeurs par défaut de l'hôte.

Le réglage de l'hôte persiste jusqu'au redémarrage de l'hôte : chaque paramètre est une écriture valable uniquement à l'exécution, que le `runner` n'annule pas lorsqu'il se termine, sauf le maintien des C-states, qui prend fin lorsque le `runner` se termine.
Après une exécution avec réglage, un drapeau qui ignore tout autre paramètre prend effet à partir du prochain redémarrage : jusque-là, le paramètre conserve sa valeur réglée, et le `runner` journalise cette valeur au démarrage.
Redémarrez un hôte partagé après avoir retiré le `runner`.

### `--no-tuning`

Désactive toutes les optimisations de réglage de l'hôte.

### `--aslr`

Ne désactive pas l'ASLR (par défaut : désactivé pour les benchmarks).

### `--nmi-watchdog`

Ne désactive pas le NMI watchdog (par défaut : désactivé pour les benchmarks).

### `--smt`

Ne désactive pas le SMT / hyper-threading (par défaut : désactivé pour les benchmarks).

### `--turbo`

Ne désactive pas le turbo boost (par défaut : désactivé pour les benchmarks).

### `--numa-balancing`

Ne désactive pas l'équilibrage NUMA automatique (par défaut : désactivé pour les benchmarks).

### `--timer-migration`

Ne désactive pas la migration des timers (par défaut : désactivée pour les benchmarks).

### `--soft-watchdog`

Ne désactive pas le soft lockup watchdog (par défaut : désactivé pour les benchmarks).

### `--ksm`

Ne désactive pas le KSM, kernel samepage merging (par défaut : désactivé pour les benchmarks).

### `--cstates`

Ne désactive pas les C-states profonds (par défaut : désactivés pour les benchmarks).

### `--no-irq-steering`

Ne dirige pas les IRQ des périphériques ni les workqueues du noyau vers les cœurs de housekeeping.

### `--no-cpuset-partition`

Ne détache pas les cœurs de benchmark de l'ordonnanceur via une partition cpuset isolée.

### `--swappiness <SWAPPINESS>`

Définit la valeur de swappiness.
Par défaut, `10` est utilisé.

### `--governor <GOVERNOR>`

Définit le gouverneur de mise à l'échelle du CPU.
Par défaut, `performance` est utilisé.

### `--perf-event-paranoid <PERF_EVENT_PARANOID>`

Définit la valeur de `perf_event_paranoid`.
Par défaut, `-1` est utilisé.

### `--thp <THP>`

Définit le mode transparent hugepage de l'hôte : `never`, `madvise`, `always` ou `leave`.
Utilisez `leave` pour conserver le mode actuel de l'hôte.
Par défaut, `never` est utilisé.
