## `--thresholds-reset`

<br />

Setzen Sie alle nicht spezifizierten Schwellenwerte für den angegebenen [Branch][branch] und [Testbed][testbed] zurück. Wenn ein Schwellenwert bereits existiert und nicht spezifiziert ist, wird sein aktuelles [Modell][model] entfernt,
unabhängig von seiner [Measure][measure], seiner [Metrik][metric] oder seinem Parameterfilter.

Zum Beispiel, wenn es zwei Schwellenwerte für den `main` Branch und das `localhost` Testbed gäbe:
- `main` Branch, `localhost` Testbed, `latency` Measure, `median` Metrik
- `main` Branch, `localhost` Testbed, `latency` Measure, `p99` Metrik

Wenn nur die `median` Metrik der `latency` Measure im `bencher run` Unterbefehl spezifiziert wird und `--thresholds-reset` verwendet wird, würde die `p99` Metrik ihr Modell entfernt bekommen.

In BMF Version 1 spezifiziert ein `--threshold-measure`, das mangels `--threshold-metric` übersprungen wird, keinen Schwellenwert,
daher entfernt `--thresholds-reset` weiterhin das Modell jedes Schwellenwerts, den der Lauf nicht mit einer Metrik spezifiziert.
