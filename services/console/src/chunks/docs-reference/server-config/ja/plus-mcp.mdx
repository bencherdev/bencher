### `plus.mcp`

このセクションでは、[Bencher MCPサーバー](/ja/docs/how-to/mcp/)を設定します。
このセクション全体は任意です。

|         名前          |                例                | デフォルト |  必須  |                                                                                                    説明                                                                                                    |
| :-------------------: | :------------------------------: | :--------: | :----: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| openai_apps_challenge | a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6 |    ---     | いいえ | このMCPサーバーを使用するアプリを提出するときにOpenAIが発行するドメイン検証トークンです。APIサーバーはこれを`/.well-known/openai-apps-challenge`でプレーンテキストとして返します。指定しない場合、このルートは`404 Not Found`を返します。 |
