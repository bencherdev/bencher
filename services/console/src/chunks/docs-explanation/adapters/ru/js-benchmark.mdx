## 🕸 JavaScript Benchmark

Адаптер JavaScript Benchmark (`js_benchmark`) ожидает вывод [Benchmark.js](https://github.com/bestiejs/benchmark.js).
Каждый Бенчмарк называется так, как его печатает Benchmark.js, без Параметров.
Измерение `throughput` (то есть `operations / second (ops/s)`) собирается со следующими Метриками:
- `mean`: скорость, которую печатает Benchmark.js
- `mean_ci95_lower` и `mean_ci95_upper`: 95% доверительный интервал, вычисленный по относительной погрешности, которую Benchmark.js печатает рядом со скоростью

У Бенчмарка из одного запуска есть только `mean`.
В первую очередь задайте Порог для Метрики `mean` с помощью `--threshold-metric mean`.
