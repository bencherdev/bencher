### `--callback-body <JSON>`

<br />

선택 사항: 콜백 요청의 JSON 본문을 설정합니다.
이 JSON 값은 문자열 안에서 다음 템플릿 변수를 사용할 수 있습니다:

| 변수                 | 확장 형식 | 값                                                   |
| -------------------- | --------- | ---------------------------------------------------- |
| `{{ project.uuid }}` | 문자열    | 프로젝트 UUID                                        |
| `{{ project.name }}` | 문자열    | 프로젝트 이름                                        |
| `{{ project.slug }}` | 문자열    | 프로젝트 슬러그                                      |
| `{{ report }}`       | 객체      | 보고서 (최대 1회)                                    |
| `{{ report.uuid }}`  | 문자열    | 보고서 UUID                                          |
| `{{ job.uuid }}`     | 문자열    | Job UUID                                             |
| `{{ job.status }}`   | 문자열    | Job 종료 상태: `processed`, `failed` 또는 `canceled` |

이 JSON 값 템플릿의 최대 크기는 64 KiB입니다.
템플릿 확장은 단일 패스로 이루어지며,
알 수 없는 템플릿 변수가 있으면 확장이 실패합니다.

이 옵션은 [`--callback-url` 옵션](#--callback-url-url)이 설정되어 있어야 합니다.
`--callback-body` 옵션을 지정하지 않으면 `bencher run` [API 엔드포인트][run post]의
응답 본문(`"{{ report }}"`)이 기본으로 사용됩니다.
