## 🐍 Python ASV

Адаптер Python ASV (`python_asv`) ожидает вывод CLI [airspeed velocity](https://github.com/airspeed-velocity/asv) [asv run](https://asv.readthedocs.io/en/stable/commands.html#asv-run).
Для наиболее полных результатов читайте файл результатов, который `asv run` записывает для коммита и окружения,
с помощью опции `--file` команды CLI `bencher run`:

<AsvJson />

Файл находится в `results_dir` asv (по умолчанию `results`),
в каталоге, названном по машине, а его имя начинается с первых 8 символов хеша коммита.

Файл результатов читается отдельно, в формате, который записывают asv 0.5 и новее.
Запустите `asv update`, чтобы преобразовать результаты, записанные более старой версией asv.
Текст, который печатает `asv run`, также читается:

<Asv />

Каждый Бенчмарк называется по своему имени через точку, например `benchmarks.TimeSuite.time_sort`.
У параметризованного бенчмарка есть Вариант для каждой комбинации его параметров.
Из файла результатов Параметры получают ключи по позиции: `@param0`, `@param1` и так далее.
Из текста они получают ключи по именам параметров, которые печатает asv.
Поэтому два формата дают одному и тому же бенчмарку разные Варианты: выберите один и придерживайтесь его.

Собираются следующие Измерения:
- `latency` (то есть `nanoseconds (ns)`), для бенчмарка `time_`: из файла результатов `median`, `p25`, `p75` и 99% доверительный интервал медианы как `median_ci99_lower` и `median_ci99_upper`; из текста `median` и `iqr`, межквартильный размах
- `memory` (то есть `bytes (B)`), для бенчмарка `mem_`: `value`
- `peak-memory` (то есть `bytes (B)`), для бенчмарка `peakmem_`: `value`

Бенчмарк `track_` учитывается как пропущенный в замечаниях Отчета, так как его единицы нет ни в файле результатов, ни в тексте.
В первую очередь задайте Порог для Метрики `median` у `latency` с помощью `--threshold-metric median`,
а для Метрики `value` у `memory` и `peak-memory`.

`asv run` завершается с ненулевым кодом, если падает любой бенчмарк, и тогда `bencher run` тоже завершается с ошибкой.
С флагом `--allow-failure` команды CLI `bencher run` запуск продолжается,
но вывод упавшей команды не отправляется, поэтому в Отчете нет ее результатов.
