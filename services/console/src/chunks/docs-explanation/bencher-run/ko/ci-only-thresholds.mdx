### `--ci-only-thresholds`

<br />

선택 사항: [임계값](/ko/docs/explanation/thresholds/)이 보고서의 메트릭을 검사하는 경우에만 CI에 결과를 게시합니다. 임계값이 존재하지 않으면 pull request 댓글이 게시되지 않습니다. pull request에서 프로젝트의 모든 작업은 하나의 댓글을 공유하므로, 보고서 중 하나라도 임계값이 존재하면 댓글이 게시됩니다. 이는 pull request 댓글에만 적용됩니다. GitHub Check는 항상 생성됩니다. 필요 조건: `--github-actions`
