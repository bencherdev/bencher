## 多个度量

在 [Bencher Metric Format (BMF) JSON][bmf] 中，
[基准测试][benchmark]条目的 `measures` 对象可以包含多个[度量][measure]的名称、slug 或 UUID 作为键。
如果指定的值是名称或 slug 且该度量尚不存在，则会为你创建它。
但是，如果指定的值是 UUID，那么该度量必须已存在。
每个度量对象将[指标][metric]名称映射到其值。

这是具有多个度量的 BMF JSON 示例：

在此示例中，`latency` 度量对象包含一个值为 `88.0` 的 `value` 指标，
而 `throughput` 度量对象包含一个值为 `5.55` 的 `value` 指标。

你可以使用 [`bencher mock` CLI 子命令][bencher mock]
以及 [`--measure` 选项][measure option]
来生成具有多个度量的模拟 BMF 数据。
我们将其用作你自己的自定义基准测试运行器的占位符。
使用 <code><a href="/zh/docs/explanation/bencher-run/">bencher run</a></code>

如果你的基准测试工具报告的度量多于你想要跟踪的度量，
请使用 <code><a href="/zh/docs/explanation/bencher-run/">bencher run</a></code> 的 [`--measure` 选项][run measure option]
只保留你指定的度量。
其他所有度量都会在存储之前被丢弃。
这与 `bencher mock` 的 `--measure` 选项不同，
后者设置 `bencher mock` 生成哪些度量。
