## Bencher Bare Metal

Bencher Bare Metal 在裸机硬件上运行您的基准测试，以消除波动，
并提供更准确、更可靠的基准测试结果。
如果您有兴趣在没有裸机硬件的情况下使用 Bencher Cloud，请查看 [Bencher Cloud 快速入门教程][quickstart]。
本教程将指导您设置并开始使用 Bencher Bare Metal。
