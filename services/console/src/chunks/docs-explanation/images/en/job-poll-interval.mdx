### `--job-poll-interval <SECONDS>`

<br />

Set the poll interval in seconds when waiting for Bare Metal [Job][job] completion.
This option requires either [the `--image` option][image] or [the `--job` option][job option] to be set.
This option conflicts with [the `--detach` option][detach].
