Встроенные [адаптеры для тестовых стендов][adapters] преобразуют вывод результатов тестирования в формат JSON формата метрик Bencher (BMF).
Пользовательские тестовые стенды должны выводить свои результаты в формате BMF JSON
и использовать [адаптер `json`][json adapter].
Смотрите [как отслеживать пользовательские бенчмарки][custom benchmarks] для полного обзора.
Чтобы сгенерировать тестовые данные BMF JSON, используйте подкоманду CLI <code><a href="/ru/docs/reference/bencher-metric-format/#bencher-mock">bencher mock</a></code>.

У BMF две версии, и у каждого Проекта есть одна из них.
Версия 1 является форматом, с которого начинается новый Проект, и именно этот формат описывает эта страница.
Версия 0 является более ранней версией, которую по-прежнему используют Проекты версии 0.
О том, как выбирается версия Отчета, и о версии 0 смотрите [версии BMF](#bmf-versions).
