## 🪄 Magic <small>(default)</small>

Der Magic-Adapter (`magic`) ist eine Obermenge aller anderen Adapter.
Aus diesem Grund ist er der Standard-Adapter für `bencher run`.
Der `magic` Adapter sollte jedoch nur zur Erkundung verwendet werden.

In BMF Version 1 versucht der `magic` Adapter zuerst [den `json` Adapter](#-json),
dann jeden Harness-Adapter in der Reihenfolge der Liste unten,
wobei er die strukturierte Ausgabe eines Harness vor dessen Textausgabe liest.
Der erste Adapter, der irgendwelche Ergebnisse liest, wird verwendet,
führen Sie also pro `bencher run` nur einen Benchmark-Harness aus.
Eine Nutzlast in BMF Version 0 für ein Projekt in BMF Version 1 wird mit einem Fehler abgelehnt, der beide Versionen nennt.

Für beste Ergebnisse sollten Sie einen Benchmark-Harness-Adapter angeben:
