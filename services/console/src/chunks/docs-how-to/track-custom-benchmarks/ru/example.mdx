В этом примере ключ `benchmark_name` является именем [Бенчмарка][benchmark].
Бенчмарк может быть идентифицирован по имени, slug или UUID.
Ключ `benchmark_name` соответствует списку записей,
и у каждой записи есть объект `measures`.
Объект `measures` может содержать в качестве ключей несколько имен, slug или UUID [Измерений][measure].
Если указано имя или slug и такое Измерение еще не существует, оно будет создано автоматически.
Однако если указан UUID, то Измерение должно уже существовать.
В этом примере `latency` является slug встроенного Измерения Latency.
У каждого Проекта по умолчанию есть Измерения Latency (т.е. `latency`) и Throughput (т.е. `throughput`),
которые измеряются в `nanosecond (ns)` и `operations / second (ops/s)` соответственно.
Каждый объект Измерения сопоставляет имена [Метрик][metric] с их значениями.
Если ваша оболочка бенчмаркинга сообщает для Измерения один результат,
назовите его Метрику `value`.

В этом примере объект Измерения `latency` содержит Метрику `value`, равную `88.0`.

У записи также может быть объект `parameters`, например `{"size": 64}`.
Каждый набор [Параметров][parameters] является отдельным [Вариантом][variant] Бенчмарка,
поэтому у одного Бенчмарка может быть несколько Вариантов.
Запись без `parameters` является Вариантом Бенчмарка без Параметров.
