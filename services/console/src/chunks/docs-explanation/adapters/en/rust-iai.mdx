## 🦀 Rust Iai

The Rust Iai Adapter (`rust_iai`) expects [Iai](https://github.com/bheisler/iai) output.

<CargoRustIai />

Each Benchmark is named by its function name, with no Parameters.
The `instructions`, `l1-accesses`, `l2-accesses`, `ram-accesses`, and `estimated-cycles` Measures are gathered.
Each is an exact count, gathered as a single `value` Metric, which is the Metric to threshold first.
The Measures for this adapter are not created by default for all projects.
However, when you use this adapter, these Measures will be automatically created for your Project.

Iai 0.1.1 panics with Valgrind 3.21 and later (for example on Ubuntu 24.04),
unless Valgrind's cache simulation is turned on.
Set `VALGRIND_OPTS=--cache-sim=yes` for the benchmark command,
and delete `target/iai` before the first run with it:
