## Несколько порогов

Возможно создать несколько порогов с одним вызовом <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code>.
При указании нескольких порогов обязательно использовать одинаковые параметры для каждого порога.
Чтобы игнорировать параметр для конкретного порога, используйте подчеркивание (`_`).
Исключение составляет `--threshold-metric`: каждому порогу нужна своя метрика, поэтому подчеркивание не может ее пропустить.

Например, если вы хотите использовать только два порога,
один для измерения Latency и другой для измерения Throughput,
то, вероятно, вы захотите установить верхнюю границу для измерения Latency
и нижнюю границу для измерения Throughput.
Поэтому вы будете использовать `--threshold-lower-boundary _` для измерения Latency
и `--threshold-upper-boundary _` для измерения Throughput.

Для одного измерения также может быть несколько порогов, которые различаются метрикой или фильтром параметров,
например один для `median` и один для `p99` измерения Latency.
Каждый порог, который соответствует варианту, проверяет его,
поэтому порог без фильтра и порог с фильтром для одной и той же метрики оба проверяют варианты, которым соответствует фильтр,
и оба создают оповещение для одной и той же регрессии.
Порог, указанный дважды в одном вызове, является одним порогом
с моделью из его последнего указания.
