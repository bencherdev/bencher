## Año nuevo, arnés nuevo

Para enero de este año, llevaba meses oyendo lo impresionante que era Claude Code. Hasta entonces no lo había probado porque Opus 4 simplemente no alcanzaba mi listón de calidad como para fiarme de su trabajo. Ahora que Opus 4.5 sí lo alcanzaba, quise darle una oportunidad también a Claude Code. La mejora que noté al pasar de usar Copilot como arnés a Claude Code fue un salto tan grande como pasar de usar Opus 4/GPT-5.2/Gemini 2.5 Pro como modelo a Opus 4.5.

Mi primerísimo fin de semana con Claude Code hice una prueba no muy controlada contra Copilot. Quería que Copilot convirtiera un PDF en un audiolibro. Incluso en "Agent Mode", Copilot avanzaba cinco o seis pasos y luego simplemente se detenía hasta que le daba otro empujón. Mientras tanto, Claude Code estaba a tope intentando construir un hipervisor a medida, después de pasar por un Plan mode exhaustivo. Me convencí por completo de que el nivel de abstracción había subido del modelo al arnés y de que Copilot nunca volvería a ponerse al día.
