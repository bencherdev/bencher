### `--detach`

<br />

Detach after submitting the Bare Metal [Job][job], without waiting for completion.
With [the `--github-actions` option][github actions], Bencher posts the GitHub Check and the pull request comment
to the Project's [linked repository][linked repository] when the Job finishes.
To send any other request when the Job finishes, use [the `--callback-url` option][callback url].
This option requires [the `--image` option][image] to be set.
This option conflicts with [the `--job-poll-interval` option][job poll interval]
and [the `--error-on-alert` flag][error on alert].
A detached run exits before its Report exists,
and with `--github-actions`, an Alert fails the GitHub Check.
