<br />

BMF バージョン 1 では、しきい値はメジャーの1つのメトリックをチェックし、そのメトリックは `--threshold-metric` で指定します。
`--threshold-metric` がまったくない `--threshold-measure` はしきい値を設定しません。
その実行は引き続き記録され、そのレポートはしきい値がスキップされたことを `--threshold-metric` を使うようにというヒントとともに警告します。

詳しくは、[しきい値とアラート](/ja/docs/explanation/thresholds/)をご覧ください。
