### `plus.mcp`

Этот раздел настраивает [MCP-сервер Bencher](/ru/docs/how-to/mcp/).
Весь раздел является необязательным.

|          Имя          |              Пример              | По умолчанию | Обязательно |                                                                                                  Описание                                                                                                  |
| :-------------------: | :------------------------------: | :----------: | :---------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| openai_apps_challenge | a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6 |     ---      |     Нет     | Токен подтверждения домена, который OpenAI выдаёт при отправке приложения, использующего этот MCP-сервер. API-сервер отдаёт его как обычный текст по адресу `/.well-known/openai-apps-challenge`. Если он не указан, этот маршрут возвращает `404 Not Found`. |
