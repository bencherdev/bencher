Los Umbrales son cómo detectas regresiones de rendimiento con Bencher. Un Umbral se asigna a una combinación única de: [Branch][branch], [Testbed][testbed], filtro de parámetros, [Measure][measure] y [Métrica][metric]. Un Umbral utiliza un [Test][tests] específico para detectar regresiones de rendimiento. La combinación de un Test y sus parámetros se llama Modelo. Un Modelo debe tener un Límite Inferior, un Límite Superior, o ambos.

- Límite Inferior
  - Se utiliza un Límite Inferior cuando un valor más pequeño indicaría una regresión de rendimiento, como con la Medida Throughput.
- Límite Superior
  - Se utiliza un Límite Superior cuando un valor más grande indicaría una regresión de rendimiento, como con la Medida Latency.

Cada Límite se utiliza para calcular un Límite de Umbral. Luego, cada nueva Métrica que comprueba el Umbral se compara con cada Límite de Umbral,
usando el historial de esa Métrica para la misma [Variante][variant]. Se genera una alerta cuando una nueva Métrica está por debajo del Límite Inferior o por encima del Límite Superior.

Al realizar [Benchmarking Continuo], es decir, benchmarking en CI, querrás crear Umbrales. Usando el subcomando <code><a href="/es/docs/explanation/bencher-run/">bencher run</a></code> de la CLI, ya especificas una Rama con [la opción `--branch`][branch option] y un Banco de Pruebas con [la opción `--testbed`][testbed option]. Así que las otras dimensiones que necesitas especificar son una Medida, con la opción `--threshold-measure`,
y la Métrica de esa Medida que se comprobará, con la opción `--threshold-metric`.
Para comprobar solo algunas Variantes, añade un filtro de parámetros con la opción `--threshold-parameters`.
Luego puedes usar la opción `--threshold-test` para especificar el Test a usar para esa Métrica. Las opciones `--threshold-min-sample-size`, `--threshold-max-sample-size` y `--threshold-window` te permiten controlar qué datos se utilizan por el Test. Finalmente, las opciones `--threshold-lower-boundary` y `--threshold-upper-boundary` te permiten establecer el Límite Inferior y el Límite Superior. Si deseas eliminar todos los Modelos que no estén especificados, puedes hacerlo con el flag `--thresholds-reset`.

- Si el Umbral no existe, se creará para ti.
- Si el Umbral existe y el Modelo especificado es el mismo, entonces el Modelo se ignora.
- Si el Umbral existe y el Modelo especificado es diferente, entonces se crea un nuevo Modelo para el Umbral.
- Si un Umbral existe y se restablece, entonces el Modelo actual se elimina del Umbral.
