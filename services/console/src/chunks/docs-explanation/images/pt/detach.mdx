### `--detach`

<br />

Desanexa após enviar o [Job em hardware dedicado][job], sem aguardar a sua conclusão.
Com [a opção `--github-actions`][github actions], o Bencher publica a Verificação do GitHub e o comentário no pull request
no [repositório vinculado][linked repository] do Projeto quando o Job termina.
Para enviar qualquer outra requisição quando o Job terminar, use [a opção `--callback-url`][callback url].
Esta opção requer que [a opção `--image`][image] esteja definida.
Esta opção entra em conflito com [a opção `--job-poll-interval`][job poll interval]
e [a flag `--error-on-alert`][error on alert].
Uma execução desanexada termina antes de seu Relatório existir,
e com `--github-actions`, um Alerta faz a Verificação do GitHub falhar.
