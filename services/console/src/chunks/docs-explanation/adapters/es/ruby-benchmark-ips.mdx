## ♦️ Ruby benchmark-ips

El adaptador Ruby benchmark-ips (`ruby_benchmark_ips`) espera la salida de [benchmark-ips](https://github.com/evanphx/benchmark-ips) en formato JSON.
Escríbela en un archivo con `x.json!`:

<BenchmarkIpsJson />

Esta salida JSON se guarda en un archivo, así que debes usar la opción `--file` de la CLI `bencher run` para especificar la ruta de ese archivo.

<RubyBenchmarkIps />

Cada Benchmark se nombra por su etiqueta.
Una etiqueta que no es una cadena, como un Hash, se nombra por su texto JSON compacto.
Cada Benchmark tiene un Parámetro, `@stats`, el modo de estadísticas que usó la ejecución: `sd` (el predeterminado) o `bootstrap` (es decir, `x.config(stats: :bootstrap)`).
La Medida `throughput` (es decir, `operations / second (ops/s)`) se recoge con estas Métricas:
- `mean`: la tasa que informa benchmark-ips
- Con `@stats` `sd`, `std_dev`: la desviación estándar de la tasa
- Con `@stats` `bootstrap`, `mean_ci_lower` y `mean_ci_upper`: el intervalo de confianza bootstrap de la tasa

Pon un Umbral primero a la Métrica `mean`, con `--threshold-metric mean`.

El adaptador Ruby benchmark-ips solo lee resultados en la versión 1 de BMF.
Un Informe para un Proyecto en la versión 0 de BMF se rechaza con un error que explica cómo pasar el Proyecto a la versión 1 de BMF.
