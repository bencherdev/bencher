### `--callback-body <JSON>`

<br />

オプション: コールバックリクエストのJSONボディを設定します。
このJSON値では、文字列の中で次のテンプレート変数を使用できます：

| 変数                 | 展開後の型   | 値                                                     |
| -------------------- | ------------ | ------------------------------------------------------ |
| `{{ project.uuid }}` | 文字列       | プロジェクトのUUID                                     |
| `{{ project.name }}` | 文字列       | プロジェクトの名前                                     |
| `{{ project.slug }}` | 文字列       | プロジェクトのスラッグ                                 |
| `{{ report }}`       | オブジェクト | レポート（1回まで）                                    |
| `{{ report.uuid }}`  | 文字列       | レポートのUUID                                         |
| `{{ job.uuid }}`     | 文字列       | JobのUUID                                              |
| `{{ job.status }}`   | 文字列       | Jobの終了状態：`processed`、`failed`、または`canceled` |

このJSON値テンプレートの最大サイズは64 KiBです。
テンプレートの展開は1回だけ行われ、
不明なテンプレート変数があると展開は失敗します。

このオプションは、[`--callback-url`オプション](#--callback-url-url)が設定されている必要があります。
`--callback-body`オプションを指定しない場合は、
`bencher run`の[APIエンドポイント][run post]のレスポンスボディ（`"{{ report }}"`）がデフォルトで使用されます。
