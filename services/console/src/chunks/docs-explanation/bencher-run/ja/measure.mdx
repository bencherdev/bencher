### `--measure <MEASURE>`

<br />

オプション：結果から、指定された[メジャー][measure]の名前、スラッグ、または UUID のみを保持します。
その他のメジャーは、何かが保存される前にすべて除外されます。
`--measure` オプションを複数回使用することで、複数のメジャーを保持できます。
保持されるのは最初の `64` 個のみで、残りについてはレポートが警告します。
結果に含まれていないメジャーは無視されます。
設定されていない場合は、すべてのメジャーが保持されます。

[measure]: /ja/docs/explanation/benchmarking/#measure
