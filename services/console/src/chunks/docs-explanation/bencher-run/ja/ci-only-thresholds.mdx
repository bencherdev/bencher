### `--ci-only-thresholds`

<br />

オプション: [しきい値](/ja/docs/explanation/thresholds/)がレポート内のメトリックをチェックする場合にのみ、CIに結果を投稿します。
しきい値が存在しない場合は、プルリクエストのコメントは投稿されません。
プルリクエスト上のプロジェクトのすべてのジョブは1つのコメントを共有するため、いずれかのレポートにしきい値が存在すればコメントは投稿されます。
これはプルリクエストのコメントにのみ適用されます。GitHubチェックは常に作成されます。
必要条件: `--github-actions`
