## Claude 帮忙拯救了圣诞节

和许多人一样，在 2025 年的寒假假期里，我终于有机会好好用一用 Claude Opus 4.5。当时我带着妻子和孩子在伦敦探望我妹妹一家。我妹妹刚生了一对双胞胎，所以我本该是去帮忙的。结果，我却窝在楼上，忙着抵御针对 Bencher 的垃圾邮件和 DDoS 攻击。Claude 在诊断问题和构思可能的解决方案方面帮了大忙。

最后我把 Bencher 迁移到了 Cloudflare 后面，并配置了 reCAPTCHA。大部分工作仍然是我自己做的，但在权衡诸多相互冲突的设计约束时，Opus 4.5 解决问题的能力有了明显的提升。不过，它也建议我做了一处改动，结果让[安装 Bencher CLI 的便捷脚本][bencher install cli]瘫痪了半天。哎呀。

[bencher install cli]: /zh/docs/how-to/install-cli/#install-cli-with-script
