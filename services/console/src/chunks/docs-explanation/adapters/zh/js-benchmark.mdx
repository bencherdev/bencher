## 🕸 JavaScript Benchmark

JavaScript Benchmark 适配器（`js_benchmark`）接受 [Benchmark.js](https://github.com/bestiejs/benchmark.js) 的输出。
每个基准测试以 Benchmark.js 打印的名称命名，没有参数。
`throughput` 度量（即 `operations / second (ops/s)`）以下列指标收集：
- `mean`：Benchmark.js 打印的速率
- `mean_ci95_lower` 和 `mean_ci95_upper`：95% 置信区间，根据 Benchmark.js 打印在速率旁的相对误差范围计算

只运行一次的基准测试只有其 `mean`。
请首先为 `mean` 指标设置阈值，使用 `--threshold-metric mean`。
