## ♦️ Ruby Benchmark

El adaptador Ruby Benchmark (`ruby_benchmark`) espera la salida del [módulo Benchmark](https://github.com/ruby/benchmark) para los métodos `#bm`, `#bmbm` y `#benchmark`.
Se requiere una etiqueta para cada benchmark.
Cada Benchmark se nombra por su etiqueta, sin Parámetros.
Se recogen estas Medidas, cada una con una sola Métrica, `value`: el tiempo que Ruby imprime en esa columna.
- `latency` (es decir, `nanoseconds (ns)`): el tiempo `real`
- `user-time` (es decir, `nanoseconds (ns)`): el tiempo `user`
- `system-time` (es decir, `nanoseconds (ns)`): el tiempo `system`
- `cpu-time` (es decir, `nanoseconds (ns)`): el tiempo `total`

Pon un Umbral primero a la Métrica `value`, con `--threshold-metric value`.

La salida se lee en la medida de lo posible.
Ruby imprime la etiqueta de una fila, ejecuta su bloque y luego imprime sus tiempos,
así que un bloque que imprime parte su fila: esa fila se cuenta como omitida en las advertencias del Informe, y las filas siguientes se siguen leyendo.
Imprime en `stderr` desde dentro de un benchmark para conservar todas las filas.
