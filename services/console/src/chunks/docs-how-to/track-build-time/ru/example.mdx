Если у вас есть скрипт, расположенный в `./my_build_script.sh`, который собирает ваш бинарный файл, тогда вы можете отслеживать время сборки этого бинарного файла с помощью <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code> и [адаптера `json`][json adapter]. Флаг `--build-time` требует [команду бенчмарка][bencher run].

<ShellJsonExample />

Обратите внимание, что [Бенчмарк][benchmark] называется `/bin/sh -c ./my_build_script.sh`. Это потому что наша команда является только единственным аргументом, поэтому <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code> по умолчанию использует форму shell для выполнения. В качестве альтернативы, если вы хотите принудительно использовать форму exec, вы можете либо предоставить несколько аргументов, либо использовать флаг `--exec`.

<ExecJsonExample />

Теперь имя [Бенчмарка][benchmark] просто `./my_build_script.sh`. Ключ `./my_build_script.sh` соответствует списку с одной записью, и объект `measures` этой записи содержит ключ `build-time`. `build-time` является slug встроенного [Измерения][measure] Build Time. Измерение Build Time не создается по умолчанию для всех проектов. Однако, когда вы используете Измерение Build Time, оно будет автоматически создано для вашего проекта. Объект Измерения Build Time содержит [Метрику][metric] `value` со временем сборки в секундах, `87.0` и `86.98` в наших примерах.

Время сборки всегда будет округлено до ближайших двух десятичных знаков. То есть, оно _никогда_ не будет длинным десятичным, как `42.666666`.
