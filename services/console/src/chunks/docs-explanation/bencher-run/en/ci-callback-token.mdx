### `--ci-callback-token <TOKEN>`

<br />

Optional: Set the authentication token used by a detached [Bare Metal Job][job] callback.

When using [the `--detach` flag][detach] and [the `--github-actions` option](#--github-actions-github_token),
the Bencher API server triggers a [`repository_dispatch`][github repository dispatch] workflow when the Job finishes.
For a Project with a [linked repository][pull requests on bare metal], Bencher creates the token itself, so this option is not needed.
To use your own token instead, set this option to a [fine-grained personal access token][github fine-grained token]
for the repository with at least the `contents: write` permission.
Bencher then sends the `repository_dispatch` event with this token, whether or not the Project has a linked repository.
The CLI requires this option on GitHub Enterprise Server and with a Bencher API server older than `v0.6.14`.
Without it, a detached run of a `claimed` Project is refused if the server has no GitHub App, the Project has no linked repository, or its linked repository is disconnected.
See [Pull Requests on Bare Metal in GitHub Actions][pull requests on bare metal] for a full overview.

> 🐰 You cannot just use the `GITHUB_TOKEN` here as it expires as soon as the current workflow finishes!
