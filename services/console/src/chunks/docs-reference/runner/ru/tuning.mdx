### Тонкая настройка хоста

Перед каждым бенчмарком `runner` применяет тонкую настройку хоста, чтобы снизить шум измерений.
По умолчанию он отключает ASLR, NMI watchdog, SMT / hyper-threading и turbo boost;
устанавливает регулятор масштабирования частоты CPU в `performance`, swappiness в `10`, а `perf_event_paranoid` в `-1`.
На хосте, который `runner` не настраивал с момента последней перезагрузки, флаги ниже вместо этого оставляют отдельные оптимизации на значениях хоста по умолчанию.

Тонкая настройка хоста сохраняется до перезагрузки хоста: каждый параметр записывается только во время выполнения, и `runner` не откатывает его при завершении, кроме удержания C-состояний, которое прекращается при завершении `runner`.
После запуска с тонкой настройкой флаг, который пропускает любой другой параметр, вступает в силу со следующей перезагрузки: до тех пор параметр сохраняет настроенное значение, а `runner` записывает это значение в журнал при запуске.
Перезагрузите общий хост после удаления `runner`.

### `--no-tuning`

Отключить все оптимизации тонкой настройки хоста.

### `--aslr`

Не отключать ASLR (по умолчанию: отключён для бенчмарков).

### `--nmi-watchdog`

Не отключать NMI watchdog (по умолчанию: отключён для бенчмарков).

### `--smt`

Не отключать SMT / hyper-threading (по умолчанию: отключён для бенчмарков).

### `--turbo`

Не отключать turbo boost (по умолчанию: отключён для бенчмарков).

### `--numa-balancing`

Не отключать автоматическую балансировку NUMA (по умолчанию: отключена для бенчмарков).

### `--timer-migration`

Не отключать миграцию таймеров (по умолчанию: отключена для бенчмарков).

### `--soft-watchdog`

Не отключать soft lockup watchdog (по умолчанию: отключён для бенчмарков).

### `--ksm`

Не отключать KSM, kernel samepage merging (по умолчанию: отключён для бенчмарков).

### `--cstates`

Не отключать глубокие C-состояния (по умолчанию: отключены для бенчмарков).

### `--no-irq-steering`

Не направлять IRQ устройств и рабочие очереди ядра на служебные ядра CPU.

### `--no-cpuset-partition`

Не отделять ядра CPU для бенчмарков от планировщика с помощью изолированного раздела cpuset.

### `--swappiness <SWAPPINESS>`

Установить значение swappiness.
По умолчанию используется `10`.

### `--governor <GOVERNOR>`

Установить регулятор масштабирования частоты CPU.
По умолчанию используется `performance`.

### `--perf-event-paranoid <PERF_EVENT_PARANOID>`

Установить значение `perf_event_paranoid`.
По умолчанию используется `-1`.

### `--thp <THP>`

Установить режим transparent hugepage на хосте: `never`, `madvise`, `always` или `leave`.
Со значением `leave` текущий режим хоста сохраняется.
По умолчанию используется `never`.
