## 🐍 Python Pytest

Python Pytest 어댑터(`python_pytest`)는 [JSON 형식(즉, `--benchmark-json results.json`)](https://pytest-benchmark.readthedocs.io/en/latest/usage.html#commandline-options)의 [pytest-benchmark](https://github.com/ionelmc/pytest-benchmark) 출력을 입력으로 받습니다.
이 JSON 출력은 파일로 저장되므로, `bencher run` CLI의 `--file` 옵션으로 그 파일 경로를 지정해야 합니다.
JSON은 모든 라운드의 시간을 담으므로, 긴 실행은 API 서버의 요청 본문 한도(기본값 4 MiB)를 넘을 수 있습니다.
파일을 작게 유지하려면 `--benchmark-max-time`으로 각 벤치마크에 쓰는 시간을 제한하세요:

<Pytest />

각 벤치마크의 이름은 `benchmarks.py::test_sort`처럼 `[param]` 접미사를 뺀 전체 이름이며,
매개변수화된 테스트의 `params`는 `{"size": 64}`처럼 그 매개변수가 됩니다.
`params`의 값이 문자열, 숫자, 불리언이 아니거나 8개를 넘으면,
벤치마크는 전체 이름을 유지하며 매개변수가 없습니다.

다음 측정이 수집됩니다:
- `latency`(즉, `nanoseconds (ns)`): `mean`, `median`, `min`, `max`, `std_dev`, 사분위수 `p25`와 `p75`, `iqr`(사분위 범위),
  pytest-benchmark가 계산하는 `lower_whisker`와 `upper_whisker`, 그리고 모든 라운드의 총 시간인 `sum`
- `throughput`(즉, `operations / second (ops/s)`): pytest-benchmark가 `ops`로 보고하는 처리율인 `mean`

한 라운드만 실행된 벤치마크에는 `std_dev`가 없습니다.
`latency`에는 먼저 `median` 메트릭에 임계값을 설정하고(`--threshold-metric median`),
`throughput`에는 `mean` 메트릭에 설정하세요.
