## \{...\} JSON

Адаптер JSON (`json`) ожидает [Bencher Metric Format (BMF) JSON][bmf].
Он идеально подходит для интеграции собственных оболочек бенчмаркинга с Bencher.
Подробнее смотрите [как отслеживать собственные бенчмарки][custom benchmarks]
и [справочник по BMF JSON][bmf].

{props.children}

Адаптер `json` читает данные в версии BMF Отчета,
которая совпадает с версией BMF Проекта, если Отчет не объявляет свою.
В BMF версии 1 каждое Измерение Варианта содержит свои именованные Метрики.
Чтобы объявить версию ваших данных в любом Проекте, используйте одну из двух версий адаптера `json`:
- `json_v1`: `bencher run --adapter json_v1` объявляет BMF версию 1
- `json_v0`: `bencher run --adapter json_v0` объявляет BMF версию 0

Данные, которые не разбираются в ожидаемой версии, отклоняются
с ошибкой, в которой названы версия, в которой они были разобраны, и источник ожидаемой версии.
Метрика, для которой в первую очередь задается Порог, это `value`, если она есть в Измерении,
затем `median`, затем `mean`, а иначе первое имя Метрики в алфавитном порядке,
причем простая статистика идет раньше границы интервала, такой как `mean_ci_lower`.

<details>
<summary>BMF версия 0</summary>

В BMF версии 0 каждое Измерение содержит `value` с необязательными `lower_value` и `upper_value`.
Любое другое имя в Измерении игнорируется.

</details>
