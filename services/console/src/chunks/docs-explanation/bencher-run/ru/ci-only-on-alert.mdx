### `--ci-only-on-alert`

<br />

Опционально: начинается публикация результатов в CI только если [сгенерировано предупреждение](/ru/docs/explanation/thresholds/#alerts).
Если предупреждение сгенерировано, все последующие результаты также будут опубликованы, даже если они не содержат предупреждений.
Все задания Проекта в запросе на вытягивание используют один общий комментарий, поэтому комментарий создается, как только хотя бы в одном из его Отчетов есть предупреждение, а затем каждое задание обновляет его.
Это относится только к комментариям к запросам на вытягивание. Проверка GitHub создается всегда.
Требуется: `--github-actions`
