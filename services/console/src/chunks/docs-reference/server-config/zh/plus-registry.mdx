### `plus.registry`

此部分指定 OCI（Open Container Initiative）注册表存储配置。
Bencher 可以作为符合 OCI 标准的容器/工件注册表运行。

如果未配置此部分，Bencher 将使用本地文件系统存储，
存储在数据库文件旁边的 `registry` 目录中。
这适用于开发和单实例部署。

对于多实例的生产部署或需要持久性时，
请配置 S3 兼容的存储。

有两种存储 `scheme`：
- `file`：将 OCI 工件存储在本地文件系统中（默认）
    - `path`：（可选）注册表数据的目录。默认为数据库文件旁边的 `registry` 目录。
- `s3`：将 OCI 工件存储在任何 S3 兼容的 Blob 存储中
    - `bucket`：存储桶名称
    - `path`：（可选）存储桶中的键前缀。开头、结尾和重复的斜杠会被移除，因此 `registry`、`registry/` 和 `/registry` 都存储在 `registry` 下。
    - `endpoint`：（AWS：可选 | 非AWS：必需）存储端点
    - `region`：（可选）存储桶区域。AWS 必需。默认为 `auto`，这是 S3 兼容存储所期望的值。
    - `access_key_id`：S3 访问密钥
    - `secret_access_key`：S3 密钥
    - `chunk_size`：（可选）上传数据存储之前缓冲的最小块大小（字节）。默认值：5 MB。
      HTTP 请求正文以小型网络帧的形式到达（通常为 8 到 64 KB）。如果不进行缓冲，每个帧都会成为一个单独的对象，每层会创建数千个对象。此值也与 S3 分段上传的最小分段大小一致。

请设置存储桶生命周期规则以中止未完成的分段上传。Blob 上传完成过程中崩溃会留下一个未完成的分段上传，服务器不会中止它。

如果您之前配置的 `path` 以斜杠开头或结尾，请在升级前将现有对象移动到规范化的前缀。`path` 为 `registry/` 时，键存储在 `registry//<project>/...` 下，现在存储在 `registry/<project>/...` 下。`path` 的每个段如果包含 ASCII 控制字符、非 ASCII 字符或 `\` `{` `^` `}` `%` `` ` `` `]` `"` `>` `[` `~` `<` `#` `|` `*` `?` 之一，也会在存储的键中被百分号编码；恰好为 `.` 或 `..` 的段会存储为 `%2E` 或 `%2E%2E`。其他所有字符（包括空格、`+`、`=`、`@` 和 `:`）都按原样存储，因此 `team#1` 变为 `team%231`，而 `team+1` 仍为 `team+1`。存储在现在会被编码的前缀下的数据也需要同样的迁移。在移动任何数据之前，请列出存储桶中实际存储的键，并与新的前缀进行比较。

|      名称      |                  示例                  | 默认值 | 必需  |                      描述                      |
| :------------: | :------------------------------------: | :----: | :---: | :--------------------------------------------: |
|      url       | "https://registry.bencher.example.com" | "http://localhost:6610" |  否   | API 服务器的外部可达 URL，用于 OCI 注册表访问。 |
|    storage     |               \{ ... \}                |  ---   |  否   | 指定注册表存储后端。省略时使用本地文件。 |
| storage.scheme |                 "s3"                   |  ---   |  是   | 指定存储 `scheme`。有关所有其他 `storage` 键，请参见上面的列表。 |
| upload_timeout |                  3600                  |  3600  |  否   | 上传会话超时时间（秒）。过期上传在启动新上传时被清理。 |
| max_body_size  |               1073741824               | 1073741824 |  否   | Blob 和清单上传的最大正文大小（字节）。超过此限制的请求将被拒绝并返回 413 Payload Too Large。默认值：1 GiB。 |
