## ➕ C++ Catch2

Адаптер C++ Catch2 (`cpp_catch2`) ожидает вывод [Catch2](https://github.com/catchorg/Catch2).
XML-репортер Catch2 (то есть `-r xml`) читается первым и дает наиболее надежные результаты, поэтому рекомендуется именно он:

<CppCatch2Xml />

Консольный вывод Catch2 также читается, по мере возможности:

<MakeCppCatch2 />

Собственный вывод вашей программы внутри таблицы Catch2 не всегда можно отличить от вывода Catch2,
поэтому бенчмарк, в который он попал, учитывается как пропущенный в замечаниях Отчета.
Вместо этого печатайте в `stderr` или используйте XML-репортер.
В консоли шириной менее 59 столбцов Catch2 переносит заголовок таблицы, поэтому каждый бенчмарк учитывается как пропущенный.

Имя Бенчмарка состоит из тестового случая, каждой секции и бенчмарка, разделенных косой чертой (то есть `Case / Section / Bench`).
Параметров нет.
Измерение `latency` собирается в наносекундах (ns)
с `mean` и `std_dev`, каждая с границами своего бутстрап-интервала.
XML называет каждый интервал с указанием его уровня доверия (то есть `mean_ci95_lower` и `mean_ci95_upper`),
а консольный вывод уровень не указывает (то есть `mean_ci_lower` и `mean_ci_upper`).
С `--benchmark-no-analysis` собирается только `mean`.

В первую очередь задайте Порог для Метрики `mean` с помощью `--threshold-metric mean`.

Catch2 завершается с ошибкой, когда бенчмарк падает, и тогда `bencher run` тоже завершается с ошибкой.
С флагом `--allow-failure` команда `bencher run` продолжает работу, но отбрасывает вывод этой итерации,
поэтому ни один из ее результатов не отправляется.
