### ⏱️ Build Time

El subcomando CLI <code><a href="/es/docs/explanation/bencher-run/">bencher run</a></code>
se puede usar para hacer seguimiento del tiempo de compilación de tus entregables con la bandera `--build-time`.
Internamente, <code><a href="/es/docs/explanation/bencher-run/">bencher run</a></code>
genera los resultados como [Bencher Metric Format (BMF) JSON][bmf] en la versión de BMF del Proyecto.
Por eso es una buena práctica usar explícitamente [el adaptador `json`][json].
Para más detalles, consulta [cómo hacer seguimiento del tiempo de compilación][build time].

La Medida `build-time` (es decir, `seconds (s)`) se recoge como una sola Métrica `value`,
que es la Métrica a la que poner un Umbral primero.
La Medida `build-time` no se crea por defecto para todos los Proyectos.
Sin embargo, cuando usas la bandera `--build-time`, esta Medida se creará automáticamente para tu Proyecto.
