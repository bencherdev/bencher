この例では、キー `my_binary` はバイナリファイルの名前です。
[ベンチマーク][benchmark]の名前として使用されます。
`my_binary` キーは1つのエントリを持つリストに対応し、
そのエントリの `measures` オブジェクトには `file-size` キーが含まれます。
`file-size` は、組み込みの File Size [メジャー][measure]のスラッグです。
File Size メジャーは、すべてのプロジェクトに対してデフォルトで作成されるわけではありません。
しかし、File Size メジャーを使用すると、プロジェクトに対して自動的に作成されます。
File Size メジャーオブジェクトには、ファイルサイズをバイト単位で持つ `value` [メトリック][metric]が含まれます（`42.0`）。

ファイルサイズは常にバイト単位で計算されます。
つまり、小数点以下の値（例：`42.5`）は*決して*含まれません。
しかし、BMF JSONは幅広い値をサポートする必要があるため、整数ではなく浮動小数点数を使用します。
