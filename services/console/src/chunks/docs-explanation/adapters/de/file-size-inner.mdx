### ⚖️ File Size

Der <code><a href="/de/docs/explanation/bencher-run/">bencher run</a></code> CLI-Unterbefehl
kann mit der Option `--file-size` verwendet werden, um die Dateigröße (d.h. die Binärgröße) Ihrer Artefakte zu verfolgen.
Die Option `--file-size` erwartet den Pfad zu der Datei, deren Größe gemessen werden soll.
Im Hintergrund gibt <code><a href="/de/docs/explanation/bencher-run/">bencher run</a></code>
die Ergebnisse als [Bencher Metric Format (BMF) JSON][bmf] in der BMF-Version des Projekts aus.
Es ist daher gute Praxis, ausdrücklich [den `json` Adapter][json] zu verwenden.
Weitere Details finden Sie unter [wie man die Dateigröße verfolgt][file size].

Die `file-size` Measure (d.h. `bytes (B)`) wird als einzelne Metrik `value` erfasst,
die die Metrik ist, für die Sie zuerst einen Schwellenwert festlegen sollten.
Die `file-size` Measure wird nicht standardmäßig für alle Projekte erstellt.
Wenn Sie jedoch die Option `--file-size` verwenden, wird diese Measure automatisch für Ihr Projekt erstellt.
Die Option `--file-size` kann mehrfach verwendet werden, um mehrere Dateigrößen zu verfolgen.
