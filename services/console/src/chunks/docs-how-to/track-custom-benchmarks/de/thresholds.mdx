## Schwellenwerte

Um Leistungsregressionen in Ihren benutzerdefinierten Benchmarks zu erkennen, fügen Sie einen [Schwellenwert][threshold] hinzu.
Ein Schwellenwert prüft eine Metrik einer Measure,
setzen Sie daher [die Option `--threshold-metric`][threshold metric option]
auf den Namen einer Metrik, die Ihr benutzerdefiniertes Benchmark-Harness meldet.
Dieser Befehl erstellt einen Schwellenwert für die `value`-Metrik der `latency`-Measure:

<ThresholdCmdExample />

Um nur einige Ihrer [Varianten][variant] zu prüfen,
setzen Sie zusätzlich [die Option `--threshold-parameters`][threshold parameters option]
auf ein JSON-Objekt der [Parameter][parameters], die sie gemeinsam haben.
(z.B.: `--threshold-parameters '{"size": 64}'`)
