### ⚖️ File Size

O subcomando CLI <code><a href="/pt/docs/explanation/bencher-run/">bencher run</a></code>
pode ser usado para acompanhar o tamanho de arquivo (ou seja, o tamanho do binário) dos seus entregáveis com a opção `--file-size`.
A opção `--file-size` espera o caminho do arquivo cujo tamanho será medido.
Por baixo dos panos, <code><a href="/pt/docs/explanation/bencher-run/">bencher run</a></code>
gera os resultados como [Bencher Metric Format (BMF) JSON][bmf] na versão do BMF do Projeto.
Por isso, é uma boa prática usar explicitamente [o adaptador `json`][json].
Para mais detalhes, veja [como acompanhar o tamanho de arquivo][file size].

A Medida `file-size` (ou seja, `bytes (B)`) é coletada como uma única Métrica `value`,
que é a Métrica para a qual definir um Limiar primeiro.
A Medida `file-size` não é criada por padrão para todos os Projetos.
No entanto, quando você usa a opção `--file-size`, esta Medida será criada automaticamente para o seu Projeto.
A opção `--file-size` pode ser usada várias vezes para acompanhar vários tamanhos de arquivo.
