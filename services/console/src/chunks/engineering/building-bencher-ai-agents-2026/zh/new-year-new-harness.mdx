## 新年新 Harness

到今年一月时，我已经听人夸 Claude Code 有多厉害好几个月了。之前我一直没去尝试，因为 Opus 4 实在达不到让我信任它工作成果的质量标准。既然 Opus 4.5 已经达到了这个标准，我也想试试 Claude Code。从把 Copilot 当作 harness 换到 Claude Code，我看到的提升幅度，和模型从 Opus 4/GPT-5.2/Gemini 2.5 Pro 换到 Opus 4.5 的飞跃一样大。

用 Claude Code 的第一个周末，我就拿它和 Copilot 做了一次不怎么严谨的对比测试。我想让 Copilot 把一份 PDF 转成有声书。即使在 “Agent Mode” 下，Copilot 也只会走五六步就停下来，直到我再戳它一下。与此同时，Claude Code 在经过一轮详尽的 Plan mode 之后，正埋头苦干，试图构建一个定制的 hypervisor。我彻底确信，抽象层级已经从模型上移到了 harness，而 Copilot 再也追不上了。
