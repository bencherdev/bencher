## Bencher Bare Metal

Bencher Bare Metal은 베어 메탈 하드웨어에서 벤치마크를 실행하여 변동성을 없애고
더 정확하고 신뢰할 수 있는 벤치마크 결과를 제공합니다.
베어 메탈 하드웨어 없이 Bencher Cloud를 사용하고자 한다면, [Bencher Cloud 빠른 시작 튜토리얼][quickstart]을 확인하세요.
이 튜토리얼은 Bencher Bare Metal을 사용할 수 있도록 설정하는 방법을 안내합니다.
