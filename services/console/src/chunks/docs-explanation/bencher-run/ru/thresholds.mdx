В BMF версии 1 Порог проверяет одну Метрику Измерения, которую задает `--threshold-metric`.
`--threshold-measure` вовсе без `--threshold-metric` не задает Порог:
запуск все равно сохраняется, а его Отчет выдает замечание о том, что Порог пропущен, с подсказкой использовать `--threshold-metric`.

Смотрите [пороги и оповещения](/ru/docs/explanation/thresholds/) для полного обзора.
