## Múltiplos Limiares

É possível criar múltiplos Limiares com a mesma invocação
<code><a href="/pt/docs/explanation/bencher-run/">bencher run</a></code>.
Ao especificar múltiplos Limiares, todas as mesmas opções devem ser usadas para cada Limiar.
Para ignorar uma opção para um Limiar específico, use um sublinhado (`_`).
A exceção é `--threshold-metric`: cada Limiar precisa de sua própria Métrica, então um sublinhado não pode ignorá-la.

Por exemplo, se você deseja usar apenas dois Limiares,
um para a Medida Latency e outro para a Medida Throughput,
provavelmente desejará definir um Limite Superior para a Medida Latency
e um Limite Inferior para a Medida Throughput.
Portanto, você utilizaria `--threshold-lower-boundary _` para a Medida Latency
e `--threshold-upper-boundary _` para a Medida Throughput.

Uma Medida também pode ter vários Limiares que diferem pela Métrica ou pelo filtro de parâmetros,
como um para a `median` e outro para o `p99` da Medida Latency.
Todo Limiar que corresponde a uma Variante a verifica,
então um Limiar sem filtro e um Limiar filtrado para a mesma Métrica verificam ambos as Variantes às quais o filtro corresponde,
e ambos geram um Alerta para a mesma regressão.
Um Limiar especificado duas vezes na mesma invocação é um único Limiar,
com o Modelo de sua última ocorrência.
