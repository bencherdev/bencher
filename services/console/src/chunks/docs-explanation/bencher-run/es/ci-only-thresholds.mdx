### `--ci-only-thresholds`

<br />

Opcional: Solo enviar resultados a CI si [existe un Umbral](/es/docs/explanation/thresholds/) para la Rama, Testbed y Medida. Si no existen Umbrales, no se publicará ningún comentario de la solicitud de extracción. Todos los trabajos de un Proyecto en una solicitud de extracción comparten un comentario, por lo que el comentario se publica si existe un Umbral para cualquiera de sus Informes. Esto solo aplica a los comentarios de la solicitud de extracción. La Verificación de GitHub siempre se crea. Requiere: `--github-actions`
