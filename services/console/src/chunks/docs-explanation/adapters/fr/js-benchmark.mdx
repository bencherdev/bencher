## 🕸 JavaScript Benchmark

L'adaptateur JavaScript Benchmark (`js_benchmark`) attend une sortie [Benchmark.js](https://github.com/bestiejs/benchmark.js).
Chaque Benchmark est nommé tel que Benchmark.js l'affiche, sans Paramètres.
La Mesure `throughput` (c.-à-d. `operations / second (ops/s)`) est recueillie avec ces Métriques :
- `mean` : le taux que Benchmark.js affiche
- `mean_ci95_lower` et `mean_ci95_upper` : l'intervalle de confiance à 95 %, calculé à partir de la marge d'erreur relative que Benchmark.js affiche à côté du taux

Un Benchmark d'une seule exécution n'a que sa `mean`.
Placez d'abord un Seuil sur la Métrique `mean`, avec `--threshold-metric mean`.
