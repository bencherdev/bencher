## 🕸 JavaScript Benchmark

JavaScript Benchmark アダプター（`js_benchmark`）は [Benchmark.js](https://github.com/bestiejs/benchmark.js) の出力を想定しています。
各ベンチマークは Benchmark.js が出力するとおりに命名され、パラメータはありません。
`throughput` メジャー（つまり `operations / second (ops/s)`）は次のメトリックで収集されます:
- `mean`: Benchmark.js が出力するレート
- `mean_ci95_lower` と `mean_ci95_upper`: 95% 信頼区間。Benchmark.js がレートの横に出力する相対誤差範囲から求めます

一回の実行のみのベンチマークは `mean` のみを持ちます。
まず `mean` メトリックにしきい値を設定してください（`--threshold-metric mean`）。
