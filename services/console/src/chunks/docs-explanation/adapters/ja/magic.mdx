## 🪄 Magic <small>(default)</small>

Magic アダプター（`magic`）は、他のすべてのアダプターのスーパーセットです。
そのため、`bencher run` のデフォルトアダプターになっています。
ただし、`magic` アダプターは探索目的でのみ使用してください。

BMF バージョン 1 では、`magic` アダプターはまず [`json` アダプター](#-json)を試し、
次に下のリストの順に各ハーネスアダプターを試します。
その際、ハーネスのテキスト出力よりも先に構造化された出力を読み取ります。
何らかの結果を読み取れた最初のアダプターが使用されるため、
一回の `bencher run` で実行するベンチマークハーネスは一つだけにしてください。
BMF バージョン 1 のプロジェクトに対する BMF バージョン 0 のペイロードは、両方のバージョンを示すエラーで拒否されます。

最良の結果を得るには、ベンチマークハーネスのアダプターを指定してください:
