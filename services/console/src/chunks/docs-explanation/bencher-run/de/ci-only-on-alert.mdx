### `--ci-only-on-alert`

<br />

Optional: Beginnen Sie mit dem Veröffentlichen von Ergebnissen in CI, nur wenn [ein Alert generiert wird](/de/docs/explanation/thresholds/#alerts). Wenn ein Alert generiert wird, werden alle nachfolgenden Ergebnisse ebenfalls veröffentlicht, selbst wenn sie keine Alerts enthalten. Alle Jobs eines Projekts in einem Pull Request teilen sich einen Kommentar, daher wird der Kommentar erstellt, sobald einer seiner Berichte einen Alert hat, und danach aktualisiert ihn jeder Job. Dies gilt nur für Pull-Request-Kommentare. Die GitHub-Prüfung wird immer erstellt. Erforderlich: `--github-actions`
