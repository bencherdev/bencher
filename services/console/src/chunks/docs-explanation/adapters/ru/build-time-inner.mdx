### ⏱️ Build Time

Подкоманду CLI <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code>
можно использовать для отслеживания времени сборки (то есть времени компиляции) ваших артефактов с помощью флага `--build-time`.
Под капотом <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code>
выводит результаты в формате [Bencher Metric Format (BMF) JSON][bmf] в версии BMF Проекта.
Поэтому хорошей практикой является явное использование [адаптера `json`][json].
Подробнее смотрите [как отслеживать время сборки][build time].

Измерение `build-time` (то есть `seconds (s)`) собирается как одна Метрика `value`,
для которой и стоит в первую очередь задать Порог.
Измерение `build-time` не создается по умолчанию для всех Проектов.
Однако при использовании флага `--build-time` это Измерение будет автоматически создано для вашего Проекта.
