## 🕸 JavaScript Benchmark

El adaptador JavaScript Benchmark (`js_benchmark`) espera la salida de [Benchmark.js](https://github.com/bestiejs/benchmark.js).
Cada Benchmark se nombra tal como lo imprime Benchmark.js, sin Parámetros.
La Medida `throughput` (es decir, `operations / second (ops/s)`) se recoge con estas Métricas:
- `mean`: la tasa que imprime Benchmark.js
- `mean_ci95_lower` y `mean_ci95_upper`: el intervalo de confianza del 95 %, a partir del margen de error relativo que Benchmark.js imprime junto a la tasa

Un Benchmark de una sola ejecución solo tiene su `mean`.
Pon un Umbral primero a la Métrica `mean`, con `--threshold-metric mean`.
