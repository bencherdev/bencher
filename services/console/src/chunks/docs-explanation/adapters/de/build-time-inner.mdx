### ⏱️ Build Time

Der <code><a href="/de/docs/explanation/bencher-run/">bencher run</a></code> CLI-Unterbefehl
kann mit dem Flag `--build-time` verwendet werden, um die Build-Zeit (d.h. die Kompilierzeit) Ihrer Artefakte zu verfolgen.
Im Hintergrund gibt <code><a href="/de/docs/explanation/bencher-run/">bencher run</a></code>
die Ergebnisse als [Bencher Metric Format (BMF) JSON][bmf] in der BMF-Version des Projekts aus.
Es ist daher gute Praxis, ausdrücklich [den `json` Adapter][json] zu verwenden.
Weitere Details finden Sie unter [wie man die Build-Zeit verfolgt][build time].

Die `build-time` Measure (d.h. `seconds (s)`) wird als einzelne Metrik `value` erfasst,
die die Metrik ist, für die Sie zuerst einen Schwellenwert festlegen sollten.
Die `build-time` Measure wird nicht standardmäßig für alle Projekte erstellt.
Wenn Sie jedoch das Flag `--build-time` verwenden, wird diese Measure automatisch für Ihr Projekt erstellt.
