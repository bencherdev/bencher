## 🕸 JavaScript Time

JavaScript Time 어댑터(`js_time`)는 Firefox, Node.js, Deno 또는 Bun의
[console.time](https://developer.mozilla.org/en-US/docs/Web/API/console/time)/[console.timeEnd](https://developer.mozilla.org/en-US/docs/Web/API/console/timeEnd) 출력을 입력으로 받습니다.
Bun은 타이머를 `stderr`로 출력하므로 `2>&1`과 함께 실행하세요.
각 벤치마크의 이름은 타이머의 레이블이며, 매개변수는 없습니다.
`latency` 측정(즉, `nanoseconds (ns)`)은 하나의 메트릭인 `value`, 즉 타이머의 지속 시간으로 수집됩니다.
먼저 `value` 메트릭에 임계값을 설정하세요(`--threshold-metric value`).

`console.timeLog`처럼 레이블이 두 번 이상 출력되면 마지막 줄만 유지되며,
그 앞의 각 줄은 보고서의 warning에서 건너뛴 것으로 집계됩니다.
Node.js와 Deno는 타이머를 `label: duration` 형태로 출력하므로,
`retry in: 5s`처럼 같은 형태의 다른 줄도 타이머로 읽힙니다.
마찬가지로 Bun의 `console.timeLog` 호출이 출력하는 추가 데이터도 별도의 타이머로 읽힐 수 있습니다.
그 밖의 출력은 벤치마크 명령의 `stdout`에 넣지 마세요.
