### `plus.github`

В этом разделе указывается конфигурация [приложения GitHub, используемого для аутентификации OAuth2](/ru/docs/how-to/github-app/).
У вас должна быть действующая лицензия Bencher Plus _Enterprise_ для хотя бы одной организации на сервере.
Весь раздел является необязательным.
Если он не указан, то аутентификация с помощью GitHub не будет включена.

|   Название    |                 Пример                  | По умолчанию | Обязательно |                                                                                                                                                                                                                                            Описание                                                                                                                                                                                                                                             |
| :-----------: | :-------------------------------------: | :----------: | :---------: | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|   client_id   |          Iv1.12864abcd1232048           |     ---      |     Да      | Указывает идентификатор клиента для вашего приложения GitHub. Идентификатор клиента отличается от идентификатора приложения. Вы можете найти идентификатор клиента на странице настроек вашего приложения. Для получения дополнительной информации о переходе на страницу настроек вашего приложения GitHub, см. [Изменение регистрации приложения GitHub](https://docs.github.com/ru/apps/maintaining-github-apps/modifying-a-github-app-registration#navigating-to-your-github-app-settings). |
| client_secret | 00000abcd12345wxyz123456789abcdefgh0000 |     ---      |     Да      |                                                                                                                                                                               Секретный ключ клиента для вашего приложения GitHub. Вы можете сгенерировать секретный ключ на странице настроек вашего приложения.                                                                                                                                                                               |
|        app         |                \{ ... \}                |   ---   |   Нет   | Указывает приложение GitHub, которое выпускает токен dispatch для связанного репозитория проекта. Это должно быть то же приложение GitHub, чей идентификатор клиента указан в `client_id`. Приложению нужен доступ на чтение и запись к содержимому репозитория. Если он не указан, то ни один проект не может связать репозиторий. |
|      app.slug      |             my-bencher-app              |   ---   |   Да   | Имя вашего приложения GitHub в его URL, как в `https://github.com/apps/my-bencher-app`. Оно указывает страницу, на которой пользователь устанавливает приложение. |
|  app.private_key   | "-----BEGIN RSA PRIVATE KEY-----\n..." |   ---   |   Да   | Закрытый ключ вашего приложения GitHub в формате PEM. Вы можете создать закрытый ключ на странице настроек вашего приложения. |
| app.webhook_secret |    0123456789abcdef0123456789abcdef     |   ---   |   Да   | Секрет вебхука вашего приложения GitHub. Вы можете задать секрет вебхука на странице настроек вашего приложения. |
