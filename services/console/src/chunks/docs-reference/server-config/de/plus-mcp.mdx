### `plus.mcp`

Dieser Abschnitt konfiguriert den [Bencher MCP-Server](/de/docs/how-to/mcp/).
Der gesamte Abschnitt ist optional.

|         Name          |             Beispiel             | Standardwert | Erforderlich |                                                                                                Beschreibung                                                                                                |
| :-------------------: | :------------------------------: | :----------: | :----------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| openai_apps_challenge | a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6 |     ---      |     Nein     | Das Token zur Domainverifizierung, das OpenAI ausstellt, wenn Sie eine App einreichen, die diesen MCP-Server verwendet. Der API-Server liefert es als Klartext unter `/.well-known/openai-apps-challenge` aus. Wenn es nicht angegeben ist, antwortet diese Route mit `404 Not Found`. |
