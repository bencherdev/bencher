## 🐍 Python Pytest

Python Pytest 适配器（`python_pytest`）接受 [JSON 格式（即 `--benchmark-json results.json`）](https://pytest-benchmark.readthedocs.io/en/latest/usage.html#commandline-options)的 [pytest-benchmark](https://github.com/ionelmc/pytest-benchmark) 输出。
此 JSON 输出保存在文件中，因此您必须使用 `bencher run` CLI 的 `--file` 选项来指定该文件路径。
JSON 包含每一轮的时间，因此长时间的运行可能会超过 API 服务器的请求体限制（默认为 4 MiB）。
请使用 `--benchmark-max-time` 限制每个基准测试所花的时间，以保持文件较小：

<Pytest />

每个基准测试以不带 `[param]` 后缀的完整名称命名，例如 `benchmarks.py::test_sort`，
参数化测试的 `params` 就是它的参数，例如 `{"size": 64}`。
当 `params` 中的某个值不是字符串、数字或布尔值，或者多于 8 个时，
基准测试保留其完整名称，并且没有参数。

收集以下度量：
- `latency`（即 `nanoseconds (ns)`）：`mean`、`median`、`min`、`max`、`std_dev`、四分位数 `p25` 和 `p75`、`iqr`（四分位距）、
  pytest-benchmark 计算的 `lower_whisker` 和 `upper_whisker`，以及 `sum`，即所有轮次的总时间
- `throughput`（即 `operations / second (ops/s)`）：`mean`，即 pytest-benchmark 报告为 `ops` 的速率

只有一轮的基准测试没有 `std_dev`。
对于 `latency`，请首先为 `median` 指标设置阈值，使用 `--threshold-metric median`；
对于 `throughput`，请首先为 `mean` 指标设置阈值。

收集 `latency` 度量（即 `nanoseconds (ns)`）。
指标有两个选项：
- `mean`（默认）：`lower_value` 和 `upper_value` 分别是低于和高于平均值（即 `value`）一个标准差。
- `median`：`lower_value` 和 `upper_value` 分别是低于和高于中位数（即 `value`）一个四分位距。

这可以在 <code><a href="/zh/docs/explanation/bencher-run/">bencher run</a></code> CLI 子命令中通过 `--average` 选项指定。
