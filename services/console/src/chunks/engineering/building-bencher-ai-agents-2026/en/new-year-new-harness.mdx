## New Year, New Harness

By January of this year, I’d been hearing about how impressive Claude Code was for months. I’d held off trying it previously because Opus 4 just didn’t meet my quality bar to trust its work. Now that Opus 4.5 had met that bar, I wanted to give Claude Code a try as well. The level of improvement I saw going from using Copilot as a harness to Claude Code was just as large of a leap as going from using Opus 4/GPT-5.2/Gemini 2.5 Pro as a model to Opus 4.5.

My very first weekend with Claude Code I did a not so controlled test against Copilot. I wanted Copilot to turn a PDF into an audiobook. Even in “Agent Mode” Copilot would get five or six steps in and then just stop until I poked it again. At the same time, Claude Code was cranking away trying to build a custom hypervisor, after going through a thorough Plan mode. I became absolutely convinced that the level of abstraction had moved up from the model to the harness and that Copilot was never going to catch up again.
