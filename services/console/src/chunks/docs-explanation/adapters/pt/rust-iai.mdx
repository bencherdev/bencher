## 🦀 Rust Iai

O Adaptador Rust Iai (`rust_iai`) espera a saída do [Iai](https://github.com/bheisler/iai).

<CargoRustIai />

Cada Benchmark é nomeado pelo seu nome de função, sem Parâmetros.
As Medidas `instructions`, `l1-accesses`, `l2-accesses`, `ram-accesses` e `estimated-cycles` são coletadas.
Cada uma é uma contagem exata, coletada como uma única Métrica `value`, que é a Métrica para a qual definir um Limiar primeiro.
As Medidas deste adaptador não são criadas por padrão para todos os Projetos.
No entanto, quando você usa este adaptador, estas Medidas serão criadas automaticamente para o seu Projeto.

O Iai 0.1.1 entra em pânico com o Valgrind 3.21 e posteriores (por exemplo, no Ubuntu 24.04),
a menos que a simulação de cache do Valgrind esteja ativada.
Defina `VALGRIND_OPTS=--cache-sim=yes` para o comando de benchmark,
e apague `target/iai` antes da primeira execução com essa opção:
