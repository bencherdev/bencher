### `plus.mcp`

此部分配置 [Bencher MCP 服务器](/zh/docs/how-to/mcp/)。
整个部分是可选的。

|         名称          |               示例               | 默认值 | 必需 |                                                                                                    描述                                                                                                    |
| :-------------------: | :------------------------------: | :----: | :--: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| openai_apps_challenge | a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6 |  ---   |  否  | 当您提交使用此 MCP 服务器的应用时，OpenAI 签发的域名验证令牌。API 服务器会在 `/.well-known/openai-apps-challenge` 以纯文本形式提供该令牌。如果未指定，该路由返回 `404 Not Found`。 |
