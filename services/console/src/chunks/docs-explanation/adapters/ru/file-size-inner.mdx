### ⚖️ File Size

Подкоманду CLI <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code>
можно использовать для отслеживания размера файлов (то есть размера бинарных файлов) ваших артефактов с помощью опции `--file-size`.
Опция `--file-size` ожидает путь к файлу, размер которого будет измерен.
Под капотом <code><a href="/ru/docs/explanation/bencher-run/">bencher run</a></code>
выводит результаты в формате [Bencher Metric Format (BMF) JSON][bmf] в версии BMF Проекта.
Поэтому хорошей практикой является явное использование [адаптера `json`][json].
Подробнее смотрите [как отслеживать размер файла][file size].

Измерение `file-size` (то есть `bytes (B)`) собирается как одна Метрика `value`,
для которой и стоит в первую очередь задать Порог.
Измерение `file-size` не создается по умолчанию для всех Проектов.
Однако при использовании опции `--file-size` это Измерение будет автоматически создано для вашего Проекта.
Опцию `--file-size` можно использовать несколько раз, чтобы отслеживать размеры нескольких файлов.
