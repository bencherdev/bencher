## 複数のメジャー

[Bencher Metric Format (BMF) JSON][bmf] では、
[ベンチマーク][benchmark]エントリの `measures` オブジェクトに、複数の[メジャー][measure]の名前、スラッグ、または UUID をキーとして含めることができます。
指定された値が名前またはスラッグで、そのメジャーがまだ存在しない場合は、自動的に作成されます。
ただし、指定された値が UUID の場合は、そのメジャーが既に存在している必要があります。
各メジャーオブジェクトは、[メトリック][metric]の名前をその値に対応させます。

以下は、複数のメジャーを持つ BMF JSON の例です:

<BmfMultiExample />

この例では、`latency` メジャーオブジェクトは `88.0` の `value` メトリックを含み、
`throughput` メジャーオブジェクトは `5.55` の `value` メトリックを含みます。

[`bencher mock` CLI サブコマンド][bencher mock]を
[`--measure` オプション][measure option]と一緒に使用して、
複数のメジャーを持つモック BMF データを生成できます。
これを独自のカスタムベンチマークランナーのプレースホルダーとして使用します。
<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code>
と [`json` アダプタ][json adapter]を使用して、
次のコマンドで複数のメジャーを持つベンチマークを追跡できます:

<RunCmdMultiExample />

ベンチマークハーネスが追跡したいよりも多くのメジャーを報告する場合は、
<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code> の [`--measure` オプション][run measure option]を使用して、
指定したメジャーのみを保持します。
それ以外のメジャーはすべて、保存される前に破棄されます。
これは `bencher mock` の `--measure` オプションとは異なります。
そちらは `bencher mock` が生成するメジャーを設定します。
