## Neues Jahr, neuer Harness

Bis zum Januar dieses Jahres hatte ich schon monatelang gehört, wie beeindruckend Claude Code sei. Ich hatte es vorher nicht ausprobiert, weil Opus 4 meine Qualitätsansprüche einfach nicht erfüllte, um seiner Arbeit zu vertrauen. Jetzt, da Opus 4.5 diese Hürde genommen hatte, wollte ich auch Claude Code eine Chance geben. Der Fortschritt, den ich beim Wechsel von Copilot als Harness zu Claude Code sah, war ein genauso großer Sprung wie der Wechsel von Opus 4/GPT-5.2/Gemini 2.5 Pro als Modell zu Opus 4.5.

Gleich an meinem allerersten Wochenende mit Claude Code habe ich einen nicht ganz so kontrollierten Vergleichstest gegen Copilot gemacht. Ich wollte, dass Copilot aus einem PDF ein Hörbuch macht. Selbst im „Agent Mode“ kam Copilot fünf oder sechs Schritte weit und blieb dann einfach stehen, bis ich ihn wieder anstupste. Zur selben Zeit legte Claude Code nach einem gründlichen Durchlauf im Plan mode richtig los und versuchte, einen eigenen Hypervisor zu bauen. Ich war felsenfest davon überzeugt, dass die Abstraktionsebene vom Modell zum Harness aufgestiegen war und dass Copilot nie wieder aufholen würde.
