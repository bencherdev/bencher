### `--fold <AGGREGATE_FUNCTION>`

<br />

Opcional: Combine vários resultados em um único resultado. \
Requer: `--iter` definido. \
Valores possíveis:
    - `min`:    Valor mínimo
    - `max`:    Valor máximo
    - `mean`:   Média dos valores
    - `median`: Mediana dos valores

Isso se aplica apenas à versão 0 do BMF.
Na versão 1, `--fold` é ignorado com um aviso no Relatório, e todas as iterações são mantidas.
