## Пример JSON в формате Bencher Metric Format (BMF)

<BmfExample />

BMF версии 1 сопоставляет имя каждого [Бенчмарка][benchmark] со списком записей, по одной для каждого [Варианта][parameters] Бенчмарка.
Каждая запись содержит:

- `parameters` (необязательно): [Параметры][parameters], с которыми был запущен Вариант, в виде объекта, значения которого являются строками, числами или логическими значениями.
  Запись без `parameters` является Вариантом с пустыми Параметрами, так же как `{}`.
- `measures`: каждое [Измерение][measure] Варианта, сопоставленное с его [Метриками][metric].
  Метрика является именем, сопоставленным с числом, например `"median": 88.0`.

В этом примере рассматриваются три Бенчмарка:

- `benchmark_name` Бенчмарк с двумя Вариантами, `size` `64` и `size` `512`, каждый с двумя Измерениями:
  - Latency (`latency`) с Метриками `median`, `mean` и `p99`
  - Throughput (`throughput`) с Метрикой `mean`
- `/bin/sh -c ./my_build_script.sh` Бенчмарк с одним Вариантом и одним Измерением для [отслеживания времени сборки][track build time] (`build-time`), с Метрикой `value`
- `my_binary` Бенчмарк с одним Вариантом и одним Измерением для [отслеживания размера файла][track file size] (`file-size`), с Метрикой `value`

Две записи с равными Параметрами являются одним Вариантом, и их Метрики объединяются.
Если обе записи содержат одну и ту же Метрику для одного и того же Измерения, побеждает более поздняя запись.
Запись без Измерений ничего не записывает.

### Metric Names

Bencher хранит каждое имя Метрики одинаково, но выбирает Метрику Измерения по умолчанию по имени,
поэтому называйте каждую статистику ее каноническим именем:
`mean`, `median`, `min`, `max`, `std_dev` и процентили `p25`, `p75`, `p90`, `p95`, `p99` и `p99_9`.
Называйте доверительный интервал по статистике, которую он ограничивает, например `mean_ci_lower` и `mean_ci_upper`,
и добавляйте его уровень, если он известен, например `mean_ci95_lower`.
Одно число, которое не является статистикой, например количество или время сборки, называйте `value`.

Если ни один [Порог][threshold] не проверяет Измерение, комментарий к запросу на вытягивание и вывод `bencher run` показывают его Метрику по умолчанию:
`value`, затем `median`, затем `mean`, затем первое имя в алфавитном порядке.
Имя доверительного интервала идет после всех остальных имен.
