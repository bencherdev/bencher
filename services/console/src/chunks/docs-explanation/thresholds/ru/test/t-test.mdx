### t-test

Т-тест (`t_test`) измеряет [интервал предсказания](https://en.wikipedia.org/wiki/Prediction_interval) (PI) для вероятности того, что новая Метрика выше или ниже среднего ваших исторических Метрик, используя [т-тест Стьюдента](https://en.wikipedia.org/wiki/Student's_t-test).

Тесты т-теста лучше всего работают, когда:
- Нет резких различий между контрольными запусками
- Контрольные запуски полностью независимы друг от друга
- Число итераций для одного контрольного запуска составляет менее 10% от исторических Метрик

Для тестов т-теста интервалы предсказания выражаются в виде десятичного кумулятивного процента. Если новая Метрика ниже определенной левосторонней кумулятивной границы (Нижняя Граница) или выше определенной правосторонней кумулятивной границы (Верхняя Граница) для ваших исторических Метрик, генерируется Оповещение. Должна быть установлена хотя бы одна из границ: Нижняя, Верхняя или обе.

- #### t-test Нижняя Граница
  - Нижняя Граница теста т-теста может быть любым положительным десятичным числом между `0.5` и `1.0`. Где `0.5` представляет среднее значение, а `1.0` — все возможные значения с левой стороны (-∞). Используется, когда меньшее значение указывает на ухудшение производительности.
  - Например, если вы использовали тест т-теста с Нижней Границей `0.977` и у вас было `25` исторических Метрик со средним `100` и выборочным стандартным отклонением `10`, лимит Нижней Границы составил бы `78.54`, и любое значение меньше `78.54` вызвало бы Оповещение.
- #### t-test Верхняя Граница
  - Верхняя Граница теста т-теста может быть любым положительным десятичным числом между `0.5` и `1.0`. Где `0.5` представляет среднее значение, а `1.0` — все возможные значения с правой стороны (∞). Используется, когда большее значение указывает на ухудшение производительности.
  - Например, если вы использовали тест т-теста с Верхней Границей `0.977` и у вас было `25` исторических Метрик со средним `100` и выборочным стандартным отклонением `10`, лимит Верхней Границы составил бы `121.46`, и любое значение больше `121.46` вызвало бы Оповещение.
- #### Границы t-test для всего Отчета
  - Для Проекта с версией BMF 1 граница t-test охватывает весь Отчет.
Верхняя Граница `0.99` означает, что Отчет без изменений вызывает Оповещение Верхней Границы не чаще 1 раза из 100, сколько бы Линий в нем ни было.
Bencher делит эту вероятность поровну между всеми проверками на этой стороне Отчета: каждый Порог, на каждой Линии, которую он проверяет, в каждой итерации.
Линия, у которой слишком мало исторических Метрик для проверки, все равно получает свою долю.
  - Например, Отчет с `200` Линиями и Верхней Границей `0.99` проверяет каждую Линию на уровне `0.99995`.
Для нормального распределения это сдвигает лимит Верхней Границы каждой Линии примерно с `2.33` до примерно `3.89` стандартных отклонений выше среднего.
  - Для Проекта с версией BMF 0 граница t-test охватывает каждую Линию отдельно.
Отчет с `200` Линиями и Верхней Границей `0.99` вызывает около `2` ложных Оповещений Верхней Границы.
