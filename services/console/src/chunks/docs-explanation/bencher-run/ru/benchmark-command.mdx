## Benchmark Command

Первым аргументом для `bencher run` является необязательная команда бенчмарка.
Это команда, которая будет выполнена и вызовет ваш harness для бенчмарков.
Её также можно задать с помощью переменной окружения `BENCHER_CMD`.
По умолчанию эта команда выполняется в shell,
который можно настроить с помощью опций [`--shell`][shell option] и [`--flag`][flag option].
Её вывод парсится адаптером harness-а для бенчмарков ([benchmark harness adapter][benchmark harness adapters]),
который можно задать с помощью опции [`--adapter`][adapter option].
Однако, если harness для бенчмарков записывает результат в файл, то также должна быть использована опция [`--file`][file option]
для указания пути к файлу вывода.
Альтернативно, чтобы отслеживать размер выходного файла (например, размер бинарника), а не его содержимое,
используйте опцию [`--file-size`][file size option] для указания пути к файлу вывода.

Если вы не хотите, чтобы команда выполнялась в shell, вы можете использовать флаг `--exec`
или просто передать дополнительные аргументы для вашей команды как дополнительные аргументы `bencher run`.

Команда бенчмарка может быть выполнена несколько раз с помощью опции [`--iter`][iter option],
а в BMF версии 0 полученные результаты можно свернуть в единый результат с помощью опции [`--fold`][fold option].
Если какая-либо из итераций завершается неудачей, то вся команда считается провалившейся,
если только не установлен флаг [`--allow-failure`][allow failure flag].

Если команда бенчмарка не указана, но указана опция [`--file`][file option],
то `bencher run` просто прочитает данные из указанного файла.
Аналогично, если команда бенчмарка не указана, но указана опция [`--file-size`][file size option],
то `bencher run` просто прочитает размер файла по указанному пути.
Опции `--file` и `--file-size` можно указывать несколько раз, чтобы читать из нескольких файлов.

<blockquote>
<details>
  <summary>🐰 Советы по использованию опции <code>-&#8288;-file</code></summary>
  Опция <code>-&#8288;-file</code> может быть использована для чтения результатов бенчмарка из файла.
  Вы можете указывать опцию <code>-&#8288;-file</code> несколько раз, чтобы читать из нескольких файлов.
  Если вы укажете опцию <code>-&#8288;-file</code> несколько раз,
  то каждый файл будет рассматриваться как отдельная <code>iteration</code> команды бенчмарка.
  При отображении эти результаты будут показаны в отдельных таблицах.

  В BMF версии 0, если вы хотите объединить эти результаты в одну <code>iteration</code>,
  то вы можете установить опцию <code>-&#8288;-iter</code> в значение <code>1</code>
  и установить опцию <code>-&#8288;-fold</code> на одну из агрегирующих функций <code>min</code>, <code>max</code> или <code>median</code>.
  Это свернёт результаты в одну <code>iteration</code>
  и отобразит их в одной таблице.
  Пожалуйста, <b>не</b> устанавливайте опцию <code>-&#8288;-fold</code> в значение <code>mean</code>.
</details>
</blockquote>

Если не указаны ни команда бенчмарка, опция [`--file`][file option],
ни опция [`--file-size`][file size option],
то `bencher run` будет читать из `stdin`.
Это позволяет сохранить вывод другой команды в файл или перенаправить его в `bencher run`.
