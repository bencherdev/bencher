Адаптеры преобразуют вывод оболочки бенчмаркинга в [Bencher Metric Format (BMF) JSON][bmf].
Адаптеры запускаются на сервере API, когда он получает новый Отчет.
Подробнее смотрите в [обзоре бенчмаркинга][benchmarking overview].
Адаптер можно указать для [подкоманды CLI `bencher run`][bencher run]
с помощью опции `--adapter`.
Если адаптер не указан, по умолчанию используется [адаптер `magic`][magic adapter].

Каждый адаптер записывает результаты в версии BMF Отчета,
которая совпадает с версией BMF Проекта, если Отчет не объявляет свою.
Новый Проект начинается с BMF версии 1.
В BMF версии 1 адаптер записывает:
- каждую статистику, которую сообщает оболочка, как отдельную именованную Метрику, например `mean`, `median` или `p99`
- Параметры из собственной структуры оболочки, поэтому у одного Бенчмарка может быть несколько Вариантов
- каждое Измерение, которое сообщает оболочка

Чтобы сохранить только некоторые из этих Измерений, перечислите их в опции `--measure` команды CLI `bencher run`.
Сервер API отбрасывает все остальные Измерения перед сохранением Отчета.
Сохраняются только первые 64 перечисленных Измерения, а об остальных Отчет выдает замечание.

Для каждого адаптера ниже указана Метрика, для которой стоит в первую очередь задать Порог.
Именно эту Метрику показывают вывод запуска и комментарий к запросу на вытягивание для Измерения, которое еще не проверяет ни один Порог.
Укажите ее с помощью опции `--threshold-metric`, когда [создаете Порог][thresholds].
Опции `--average` и `--fold` предназначены только для BMF версии 0.
В BMF версии 1 обе игнорируются, а в Отчете появляется замечание.

Адаптеры Rust Divan, JavaScript tinybench, JavaScript Deno, JavaScript mitata и Ruby benchmark-ips читают результаты только в BMF версии 1.
Имя Бенчмарка в BMF версии 1 может отличаться от его имени в BMF версии 0,
поэтому у Проекта, который переходит с BMF версии 0 на BMF версию 1, некоторые Бенчмарки могут начаться заново.
Если адаптер читает результаты и в BMF версии 0, его раздел заканчивается описанием того, как он это делает.
