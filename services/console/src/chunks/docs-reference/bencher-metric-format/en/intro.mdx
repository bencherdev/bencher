Built-in [benchmark harness adapters][adapters] convert benchmark output into Bencher Metric Format (BMF) JSON.
Custom benchmarking harnesses should output their results as BMF JSON
and use [the `json` adapter][json adapter].
See [how to track custom benchmarks][custom benchmarks] for a full overview.
To generate mock BMF JSON data, use the <code><a href="/docs/reference/bencher-metric-format/#bencher-mock">bencher mock</a></code> CLI subcommand.

BMF has two versions, and every Project has one of them.
Version 1 is the format a new Project starts on, and it is the format this page describes.
Version 0 is the earlier version, which version 0 Projects still use.
See [BMF versions](#bmf-versions) for how a Report's version is chosen and for version 0.
