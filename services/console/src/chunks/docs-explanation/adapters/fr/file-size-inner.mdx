### ⚖️ File Size

La sous-commande CLI <code><a href="/fr/docs/explanation/bencher-run/">bencher run</a></code>
peut être utilisée pour suivre la taille de fichier (c.-à-d. la taille du binaire) de vos livrables avec l'option `--file-size`.
L'option `--file-size` attend le chemin du fichier dont la taille sera mesurée.
En coulisses, <code><a href="/fr/docs/explanation/bencher-run/">bencher run</a></code>
produit les résultats en [Bencher Metric Format (BMF) JSON][bmf] dans la version de BMF du Projet.
C'est donc une bonne pratique d'utiliser explicitement [l'adaptateur `json`][json].
Pour plus de détails, voir [comment suivre la taille de fichier][file size].

La Mesure `file-size` (c.-à-d. `bytes (B)`) est recueillie comme une seule Métrique `value`,
qui est la Métrique sur laquelle placer un Seuil en premier.
La Mesure `file-size` n'est pas créée par défaut pour tous les Projets.
Cependant, lorsque vous utilisez l'option `--file-size`, cette Mesure sera automatiquement créée pour votre Projet.
L'option `--file-size` peut être utilisée plusieurs fois pour suivre plusieurs tailles de fichier.
