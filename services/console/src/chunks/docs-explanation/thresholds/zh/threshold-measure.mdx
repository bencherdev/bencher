## `--threshold-measure <MEASURE>`

<br />

使用指定的[度量][measure]名称、标识符或UUID作为阈值。如果指定的值是名称或标识符且度量不存在，将会为您创建它。但是，如果指定的值是UUID，那么度量必须已经存在。

例如，要为 Latency 度量使用阈值，你可以输入`--threshold-measure latency`。与 [`--threshold-metric` 选项](#--threshold-metric-metric) 搭配使用，以指定阈值检查该度量的哪个指标。

[measure]: /zh/docs/explanation/benchmarking/#measure
