## 🦀 Rust Bench

Адаптер Rust Bench (`rust_bench`) ожидает вывод [libtest bench](https://doc.rust-lang.org/rustc/tests/index.html#benchmarks).

<CargoRustBench />

В nightly Rust libtest также может выводить результаты в виде JSON (то есть `-Z unstable-options --format json`),
и адаптер читает его раньше текстового вывода:

<CargoRustBenchJson />

Каждый Бенчмарк называется по имени своего теста, без Параметров.
Измерение `latency` (то есть `nanoseconds (ns)`) собирается с двумя Метриками:
- `median`: медиана времени на итерацию
- `range`: значение `+/-` из libtest, то есть разброс между самым быстрым и самым медленным из его замеров

Если бенчмарк задает число байт на итерацию (то есть `b.bytes`),
то Измерение `bytes-throughput` (то есть `bytes / second (B/s)`) также собирается как его `median`.
В первую очередь задайте Порог для Метрики `median` с помощью `--threshold-metric median`.

Вывод Criterion `--output-format bencher` печатает те же строки, что и libtest,
поэтому его читает этот адаптер, а `range` в нем равен стандартному отклонению Criterion.
