### `--measure <MEASURE>`

<br />

Опционально: оставить в результатах только указанное по имени, slug или UUID [Измерение][measure].
Все остальные Измерения отбрасываются до того, как что-либо будет сохранено.
Можно оставить несколько Измерений, используя опцию `--measure` несколько раз.
Сохраняются только первые `64`, а об остальных Отчет выдает замечание.
Измерение, которого нет в результатах, игнорируется.
Если опция не задана, сохраняются все Измерения.

[measure]: /ru/docs/explanation/benchmarking/#measure
