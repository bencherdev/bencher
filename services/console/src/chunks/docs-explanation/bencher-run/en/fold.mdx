### `--fold <AGGREGATE_FUNCTION>`

<br />

Optional: Fold multiple results into a single result using an aggregate function. \
Requires: `--iter` to be set. \
Possible values:
    - `min`:    Minimum value
    - `max`:    Maximum value
    - `mean`:   Mean of values
    - `median`: Median of values

This applies at BMF version 0 only.
At version 1, `--fold` is ignored with a Report warning, and every iteration is kept.
