## ♦️ Ruby Benchmark

Ruby Benchmark アダプター（`ruby_benchmark`）は、`#bm`、`#bmbm`、`#benchmark` メソッドの [Benchmark モジュール](https://github.com/ruby/benchmark) の出力を想定しています。
各ベンチマークにはラベルが必要です。
各ベンチマークはそのラベルで命名され、パラメータはありません。
次のメジャーが収集され、それぞれ単一のメトリック `value`（Ruby がその列に出力する時間）を持ちます。
- `latency`（つまり `nanoseconds (ns)`）: `real` 時間
- `user-time`（つまり `nanoseconds (ns)`）: `user` 時間
- `system-time`（つまり `nanoseconds (ns)`）: `system` 時間
- `cpu-time`（つまり `nanoseconds (ns)`）: `total` 時間

まず `value` メトリックにしきい値を設定してください（`--threshold-metric value`）。

出力はベストエフォートで読み取られます。
Ruby は行のラベルを出力し、そのブロックを実行してから、時間を出力します。
そのため、出力を行うブロックはその行を分断します。その行はレポートの警告でスキップとして数えられ、それ以降の行は引き続き読み取られます。
すべての行を保持するには、ベンチマーク内からは `stderr` に出力してください。
