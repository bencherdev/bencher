## 複数の閾値

同じ<code><a href="/ja/docs/explanation/bencher-run/">bencher run</a></code>の呼び出しで複数の閾値を作成することが可能です。
複数の閾値を指定する場合、各閾値で同じオプションを使用する必要があります。
特定の閾値に対してオプションを無視したい場合は、アンダースコア（`_`）を使用します。
ただし `--threshold-metric` は例外です。各閾値にはそれぞれ独自のメトリックが必要なため、アンダースコアでスキップすることはできません。

例えば、2つの閾値を使用したい場合、
一つは Latency メジャー用、もう一つは Throughput メジャー用とすると、
Latency メジャーには上限値を設定し、
Throughput メジャーには下限値を設定することが考えられます。
したがって、Latency メジャーには`--threshold-lower-boundary _`を使用し、
Throughput メジャーには`--threshold-upper-boundary _`を使用すると良いでしょう。

1つのメジャーに対して、メトリックやパラメータフィルタが異なる複数の閾値を設定することもできます。
例えば、Latency メジャーの `median` 用と `p99` 用の閾値です。
バリアントに一致するすべての閾値がそのバリアントをチェックします。
そのため、同じメトリックに対するフィルタなしの閾値とフィルタ付きの閾値は、どちらもフィルタに一致するバリアントをチェックし、
同じリグレッションに対してどちらもアラートを生成します。
同じ呼び出しの中で2回指定された閾値は1つの閾値となり、
そのモデルは最後に指定されたものになります。
