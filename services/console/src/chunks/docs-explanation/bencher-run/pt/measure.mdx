### `--measure <MEASURE>`

<br />

Opcional: Mantém dos resultados apenas o nome, slug ou UUID da [Medida][measure] especificada.
Todas as outras Medidas são descartadas antes que qualquer coisa seja armazenada.
Várias Medidas podem ser mantidas usando a opção `--measure` várias vezes.
Apenas as primeiras `64` são mantidas, e o Relatório avisa sobre o restante.
Uma Medida que os resultados não contêm é ignorada.
Se não for definida, todas as Medidas são mantidas.

[measure]: /pt/docs/explanation/benchmarking/#measure
