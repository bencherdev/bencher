## BMF Versions

모든 프로젝트에는 BMF 버전이 있으며, 새 프로젝트는 버전 1에서 시작합니다.
보고서는 `bmf_version` 필드에 선언한 버전으로 읽히며, 선언이 없으면 해당 프로젝트의 버전으로 읽힙니다.
<code><a href="/ko/docs/explanation/bencher-run/">bencher run</a></code> CLI 서브커맨드는 프로젝트의 버전을 읽고 모든 보고서에 그 버전을 선언합니다.
아직 존재하지 않는 프로젝트는 실행이 버전 1로 생성하므로 버전 1로 읽힙니다.

선언된 버전은 계약입니다.
다른 버전으로 파싱되는 결과는 `400 Bad Request`를 받으며,
이 오류는 두 버전을 모두 밝히고, 기대한 버전이 어디에서 왔는지 알려주며, 해결 방법을 나열합니다.

[`json` 어댑터][json adapter]는 보고서의 버전으로 JSON을 읽습니다.
`json_v0` 어댑터와 `json_v1` 어댑터는 각각 자신의 버전으로 JSON을 읽으며,
`bencher run --adapter json_v0` 또는 `--adapter json_v1`은 어떤 프로젝트에서든 그 버전을 선언합니다.

프로젝트를 편집할 수 있는 사용자는
`bencher project update --bmf-version 1`, API 또는 프로젝트 설정의 Move to version 1 버튼으로 프로젝트를 버전 0에서 버전 1로 옮깁니다.
프로젝트를 버전 0으로 되돌릴 수 있는 것은 서버 관리자뿐입니다.

<summary>BMF 버전 0</summary>

BMF 버전 0은 이전 버전으로, 버전 0 프로젝트에서 여전히 사용됩니다.
각 벤치마크 이름을 그 측정에, 각 측정을 메트릭 트리플에 대응시킵니다:

<BmfV0Example />

버전 0에서는 벤치마크에 매개변수가 없으므로 변형(Variant)은 하나입니다.
측정은 필수인 `value`와 선택 사항인 `lower_value` 및 `upper_value`를 가집니다.
버전 0은 이 세 이름만 읽습니다. 측정 안의 다른 이름은 warning 없이 무시됩니다.
