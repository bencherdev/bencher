### t-test

t-테스트(`t_test`)는 [스튜던트 t-테스트](https://en.wikipedia.org/wiki/Student's_t-test)를 사용하여 새로운 메트릭이 과거 메트릭의 평균보다 위 또는 아래에 있을 가능성에 대한 [예측 구간](https://en.wikipedia.org/wiki/Prediction_interval) (PI)을 측정합니다.

t-테스트는 다음과 같은 경우에 가장 잘 작동합니다:
- 벤치마크 실행 간에 극단적인 차이가 없는 경우
- 벤치마크 실행이 서로 완전히 독립적인 경우
- 단일 벤치마크 실행의 반복 횟수가 과거 메트릭의 10% 미만인 경우

t-테스트의 경우, 예측 구간은 소수 누적 백분율로 표현됩니다.
새로운 메트릭이 특정 좌측 누적 백분율(하한계)보다 아래에 있거나 특정 우측 누적 백분율(상한계)보다 위에 있는 경우 알림이 생성됩니다.
하한계, 상한계, 또는 둘 다 설정되어야 합니다.

- #### t-test 하한계
  - t-테스트 하한계는 `0.5`와 `1.0` 사이의 어떤 양수 소수도 될 수 있습니다.
`0.5`는 평균을 나타내고 `1.0`은 가능한 모든 좌측 값을 나타냅니다 (-∞).
더 작은 값이 성능 퇴행을 나타내는 경우에 사용됩니다.
  - 예를 들어, 하한계가 `0.977`인 t-테스트를 사용하였고,
`25`개의 과거 메트릭에 평균 `100`과 표본 표준 편차 `10`이 있는 경우,
하한계 제한은 `78.54`이 되고
`78.54` 미만의 값은 알림을 생성합니다.
- #### t-test 상한계
  - t-테스트 상한계는 `0.5`와 `1.0` 사이의 어떤 양수 소수도 될 수 있습니다.
`0.5`는 평균을 나타내고 `1.0`은 가능한 모든 우측 값을 나타냅니다 (∞).
더 큰 값이 성능 퇴행을 나타내는 경우에 사용됩니다.
  - 예를 들어, 상한계가 `0.977`인 t-테스트를 사용하였고,
`25`개의 과거 메트릭에 평균 `100`과 표본 표준 편차 `10`이 있는 경우,
상한계 제한은 `121.46`가 되고
`121.46` 초과의 값은 알림을 생성합니다.
- #### 보고서 전체에 대한 t-테스트 경계
  - BMF 버전 1의 프로젝트에서 t-테스트 경계는 보고서 전체를 다룹니다.
상한 경계가 `0.99`이면 변경이 없는 보고서는 라인 수와 관계없이 최대 100번에 1번 상한 경계 알림을 생성합니다.
Bencher는 그 확률을 보고서의 그쪽 모든 검사에 균등하게 나눕니다: 각 Threshold, 그것이 검사하는 각 라인, 각 반복입니다.
검사하기에 과거 메트릭이 너무 적은 라인도 자신의 몫을 받습니다.
  - 예를 들어, `200`개의 라인과 상한 경계 `0.99`를 가진 보고서는 각 라인을 `0.99995`에서 검사합니다.
정규 분포에서는 각 라인의 상한 경계 제한이 평균 위 약 `2.33` 표준 편차에서 약 `3.89` 표준 편차로 이동합니다.
  - BMF 버전 0의 프로젝트에서 t-테스트 경계는 각 라인을 따로 다룹니다.
`200`개의 라인과 상한 경계 `0.99`를 가진 보고서는 약 `2`개의 잘못된 상한 경계 알림을 생성합니다.
