## Сообщения Runner

Сообщения, отправляемые от Runner к серверу.

| Event       | Описание                                          | Полезная нагрузка                                                       |
| ----------- | ------------------------------------------------- | ----------------------------------------------------------------------- |
| `ready`     | Runner простаивает и запрашивает Job              | Необязательные `poll_timeout` (1-900 с) и метаданные `runner` (`os`, `arch`, `version`, необязательный `channel` обновления и необязательная `checksum` бинарного файла), а также необязательное состояние дисков `health` |
| `paused`    | Runner простаивает, но не берёт Job, пока не устранены причины паузы; сервер удерживает опрос и отвечает `no_job` | `reasons` (у каждой есть `kind`: `raid` или `maintenance`), `since` и все поля `ready` |
| `running`   | Настройка Job завершена, бенчмарк запускается     | Нет                                                                     |
| `heartbeat` | Периодический сигнал жизнеспособности (примерно раз в секунду) | Нет                                                         |
| `completed` | Бенчмарк успешно завершён                         | `job` (UUID сообщения `job`) и `results` (вывод этого запуска)          |
| `failed`    | Бенчмарк завершился с ошибкой                     | `job` (UUID сообщения `job`), `results` и `error`                       |
| `canceled`  | Подтверждает отмену от сервера                     | `job` (UUID сообщения `job`)                                            |

UUID сообщения `job` обозначает это выполнение, а не Job.
Runner возвращает его, поэтому результат точно указывает на своё выполнение,
даже если он отправлен повторно после того, как ушло другое выполнение той же Job.
