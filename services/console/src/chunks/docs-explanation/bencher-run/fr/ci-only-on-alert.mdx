### `--ci-only-on-alert`

<br />

Optionnel : ne commencer à publier les résultats vers CI que si [une alerte est générée](/fr/docs/explanation/thresholds/#alerts).
Si une alerte est générée, alors tous les résultats de suivi seront également publiés même s'ils ne contiennent aucune alerte.
Tous les travaux d'un Projet sur une pull request partagent un seul commentaire, donc le commentaire est créé dès que l'un de ses Rapports a une alerte, puis chaque travail le met à jour.
Cela ne s'applique qu'aux commentaires de pull request. La vérification GitHub est toujours créée.
Requiert : `--github-actions`
