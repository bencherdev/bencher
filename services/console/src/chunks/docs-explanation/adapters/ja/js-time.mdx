## 🕸 JavaScript Time

JavaScript Time アダプター（`js_time`）は、Firefox、Node.js、Deno、または Bun による
[console.time](https://developer.mozilla.org/en-US/docs/Web/API/console/time)/[console.timeEnd](https://developer.mozilla.org/en-US/docs/Web/API/console/timeEnd) の出力を想定しています。
Bun はタイマーを `stderr` に出力するため、`2>&1` を付けて実行してください。
各ベンチマークはタイマーのラベルで命名され、パラメータはありません。
`latency` メジャー（つまり `nanoseconds (ns)`）は、単一のメトリック `value`（タイマーの所要時間）で収集されます。
まず `value` メトリックにしきい値を設定してください（`--threshold-metric value`）。

`console.timeLog` のようにラベルが複数回出力された場合は、最後の行のみが保持され、
それより前の各行はレポートの警告でスキップとして数えられます。
Node.js と Deno はタイマーを `label: duration` の形で出力するため、
`retry in: 5s` のような同じ形のその他の行もタイマーとして読み取られます。
同様に、Bun の `console.timeLog` 呼び出しが出力する追加データも、独立したタイマーとして読み取られる場合があります。
その他の出力は、ベンチマークコマンドの `stdout` に含めないでください。
