### `--callback-body <JSON>`

<br />

Необязательно: Задает JSON-тело запроса callback.
Это JSON-значение может использовать в строке любые из следующих переменных шаблона:

| Переменная           | Раскрывается как | Значение                                                     |
| -------------------- | ---------------- | ------------------------------------------------------------ |
| `{{ project.uuid }}` | Строка           | UUID Проекта                                                 |
| `{{ project.name }}` | Строка           | Название Проекта                                             |
| `{{ project.slug }}` | Строка           | Slug Проекта                                                 |
| `{{ report }}`       | Объект           | Отчет (не более одного раза)                                 |
| `{{ report.uuid }}`  | Строка           | UUID отчета                                                  |
| `{{ job.uuid }}`     | Строка           | UUID Job                                                     |
| `{{ job.status }}`   | Строка           | Конечное состояние Job: `processed`, `failed` или `canceled` |

Максимальный размер этого шаблона JSON-значения составляет 64 КиБ.
Шаблон раскрывается за один проход,
и любая неизвестная переменная шаблона приводит к ошибке раскрытия.

Эта опция требует, чтобы была задана [опция `--callback-url`](#--callback-url-url).
Если опция `--callback-body` не указана, по умолчанию используется тело ответа [эндпоинта API][run post]
`bencher run` (`"{{ report }}"`).
