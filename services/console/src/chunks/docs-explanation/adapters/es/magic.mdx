## 🪄 Magic <small>(default)</small>

El adaptador Magic (`magic`) es un superconjunto de todos los demás adaptadores.
Por esa razón, es el adaptador predeterminado para `bencher run`.
Sin embargo, el adaptador `magic` debe usarse solo para exploración.

En la versión 1 de BMF, el adaptador `magic` prueba primero [el adaptador `json`](#-json),
luego cada adaptador de arnés en el orden de la lista siguiente,
leyendo la salida estructurada de un arnés antes que su salida de texto.
Se usa el primer adaptador que lea algún resultado,
así que ejecuta solo un arnés de benchmark por cada `bencher run`.
Una carga en la versión 0 de BMF para un Proyecto en la versión 1 de BMF se rechaza con un error que nombra ambas versiones.
