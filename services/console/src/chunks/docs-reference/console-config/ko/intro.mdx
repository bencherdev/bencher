Bencher Console UI는 별도의 설정이 필요하지 않습니다.
다만, 다음 환경 변수를 사용하여 일부 기본값을 필요에 맞게 사용자화할 수 있습니다:

- `BENCHER_API_URL`: [Bencher API 서버][server config]의 URL입니다.
  Console 서버는 브라우저의 모든 요청을 Console 자체 URL의 `/api` 아래에서 이 URL로 중계합니다.
  기본값은 `http://localhost:6610`로 설정되어 있습니다.
- `INTERNAL_API_URL`: Console 서버가 다른 주소로 API 서버에 접근할 때,
  `BENCHER_API_URL` 대신 중계하는 URL입니다.
  [Docker Compose][docker compose]는 이를 두 서버가 공유하는 Docker 네트워크의 API 서버 컨테이너인 `http://bencher_api:6610`으로 설정하며,
  [`bencher up`][bencher up]도 `BENCHER_API_URL`이 설정되지 않았거나 `localhost`와 같은 루프백 주소를 가리키면 같게 설정합니다.
  그 외에는 기본적으로 설정되어 있지 않습니다.
- `BENCHER_RELAY_SECRET`: Console 서버가 [API 서버의 `security.relay_secret`][security]과 공유하는 비밀 값입니다.
  두 서버에 같은 값을 설정하면, API 서버는 Console 서버가 중계하는 브라우저의 IP 주소를 신뢰하고,
  Console 서버가 중계한 요청에서만 세션을 인정합니다.
  기본적으로 설정되어 있지 않습니다.
- `OAUTH_GITHUB`: [Self-Hosted GitHub App][github app]을 사용한 `Login with GitHub`을 활성화하려면 `true`로 설정하세요.
  이 기능은 [Bencher Plus Enterprise 플랜][bencher plus enterprise]이 필요합니다. 기본적으로 설정되어 있지 않습니다.
- `OAUTH_GOOGLE`: [Self-Hosted Google OAuth2][google oauth2]를 사용한 `Login with Google`을 활성화하려면 `true`로 설정하세요.
  이 기능은 [Bencher Plus Enterprise 플랜][bencher plus enterprise]이 필요합니다. 기본적으로 설정되어 있지 않습니다.
